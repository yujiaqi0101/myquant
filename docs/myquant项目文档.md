# myquant项目文档

# 项目背景

做一个一站式量化交易系统，可交易品种包含股票，etf，（暂时先不做期货，期权，债券），为个人定制快速的量化方案。

# 项目规则

数据库中的市场数据（标的、K线等）必须是干净的、可信任的，模拟数据绝不写入数据库。

每个完成的功能都要做好最小单元的测试；

# 系统功能

## 数据采集

从指定数据源中获取数据，采集模块需要做模块化处理，即每个采集表都是独立可运行的，这样可以做到当前使用东财掘金量化获取的交易日历，然后写入的系统交易日历表，未来改成从tushare获取的交易日历表，再写入系统交易日历表

### 数据源

由于各数据源结构不同，所以从各数据获取数据都放在各数据源的定制表中，然后根据一定的处理逻辑放入程序使用的表中

目前已知可能对接的数据源:

|数据源|表前缀|
|---|---|
|东财掘金量化|dcjj|
|国金QMT|gjqmt|
|AKShare|ak|
|tushare|tu|
|通达信|tdx|

从外部获取的金额都前复权的，当某只股票有分红/配股，该股票历史数据需要从新获取，所以需要找到除权除息日

### 数据检查

根据一定规则检查股票，ETF，指数数据是否有缺失，缺了哪些数据

|股票代码|上市时间|周期|数据开始时间|数据结束时间|上次分红/配股时间|最新统计日期|
|---|---|---|---|---|---|---|

## 任务管理

任务管理模块主要实现系统内后台任务的执行和监控，实现任务队列，任务定时执行，失败任务重试等等功能。

任务队列可以根据服务器配置来手工配置队列数量，多任务并行执行不会相互影响。

后台任务包括，数据采集，市场分析，估值分析；

支持将来更多任务的加入；



## 执行日志

自动记录每次回测执行的条件和结果

支持按因子、类型、状态筛选查询



## 运行日志系统

**控制台输出**：带颜色的实时日志（INFO绿色、WARNING黄色、ERROR红色）

**文件记录**：按天轮转，保留30天，存储在 `logs/aquant_YYYYMMDD.log`

**日志级别**：支持 DEBUG/INFO/WARNING/ERROR 四级

**命令行控制**：`--log-level` 设置级别，`--no-log-file` 仅控制台输出



## 数据源配置，回测/分析一律从数据库读取，缺数据直接报错退出。

**数据来源**（通过 `config/config.json` → `data_source.source` / `data_source.routing` 配置）：
- **database**：本地 SQLite 数据库
- **eastmoney**：东财掘金 API（用于同步行情和因子数据）
- 优先级：命令行 `--data-source` > `config.json` > 默认值 database
