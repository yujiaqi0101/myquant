## 1. 总体原则

### 1.1 统一事件驱动内核

myquant 采用统一事件驱动内核架构，所有策略基于 `src/core/strategy.py` 的 `Strategy` 基类开发：

```
策略层 (Strategy)           on_event(event, context) → 事件驱动决策
    ↓
上下文层 (Context)          submit_order / get_positions / get_account / history / get_db
    ↓
引擎层 (Engine)             BacktestEngine / PaperEngine / LiveEngine（策略不感知）
    ↓
风控层 (RiskManager)        法定风控 + 订单级 + 组合级 三层过滤
    ↓
撮合层 (Execution)          扣现金、记成交、推 TradeEvent
```

**核心设计**：策略不感知运行模式（回测/模拟盘/实盘），同一份策略代码可在三种引擎间无缝切换。策略开发者只需关注 `Strategy` 基类、`Context` 接口和 `EventType` 事件，不需要了解引擎内部实现。

### 1.2 三种运行模式

| 模式 | 数据来源 | 持久化 | 策略代码差异 |
|------|----------|--------|--------------|
| 回测 | 历史数据库 | 内存 | 无差异 |
| 模拟盘 | 实时/历史数据库 | SQLite（多策略子账户） | 无差异 |
| 实盘 | 券商实时行情 | 券商 API | 无差异 |

### 1.3 策略开发边界

策略层只负责**信号生成与下单决策**，不负责执行细节：

| 职责 | 归属 | 说明 |
|------|------|------|
| 选股信号、调仓频率、买卖逻辑 | 策略层 | 策略核心 |
| 仓位计算、佣金扣减、撮合 | 引擎层 | 策略不参与 |
| 止损/止盈/动态止盈 | 风控层 | 通过 `RiskManager` 实现 |
| 涨跌停/ST/新股/停牌/T+1 过滤 | 风控层 | 法定风控自动处理 |

### 1.4 禁止事项

- 禁止在策略层直接调用 `DatabaseManager` 写数据（只读查询通过 `context.get_db()`）
- 禁止在策略层手写仓位计算、佣金扣减、撮合逻辑（交给引擎和风控层）
- 禁止在 `on_event` 中执行阻塞操作（写文件、起线程、网络请求）
- 禁止持有不可序列化对象（数据库连接、文件句柄）作为策略属性
- 禁止在策略层实现止损/止盈/动态止盈（委托给 `RiskManager`）

## 2. 目录结构与命名

### 2.1 标准目录结构

```
src/strategies/
├── __init__.py                     # 自动发现入口（调用 auto_discover）
├── <策略名>/                        # 策略目录名与策略名一致
│   ├── __init__.py                 # Python 包标记（空文件即可）
│   ├── <策略名>.py                 # 策略实现文件
│   └── 策略路径.md                  # 策略说明
```

### 2.2 命名规则

| 项目 | 规则 | 示例 |
|------|------|------|
| 策略名 | snake_case，业务语义 | `small_cap`、`manual_trade` |
| 策略目录名 | 与策略名一致 | `small_cap/`、`manual_trade/` |
| 策略文件名 | `<策略名>.py` | `small_cap.py`、`manual_trade.py` |
| 策略类名 | PascalCase | `SmallCapStrategy`、`ManualTradeStrategy` |
| 策略 `name` 属性 | 与注册名一致 | `small_cap`、`manual_trade` |

### 2.3 必备文件

每个策略目录必须包含 3 个文件：

1. `__init__.py` — 空文件即可
2. `<策略名>.py` — 策略实现
3. `策略路径.md` — 策略说明（模板见 [§10](#10-策略路径md-模板)）

### 2.4 自动发现

`auto_discover("src.strategies")` 扫描 `src/strategies/` 下所有子目录，导入其中所有 `.py` 文件（跳过 `__init__` 和 `_` 开头文件），触发 `@register_strategy` 装饰器完成注册。

## 3. 策略基类契约（Strategy）

### 3.1 继承与接口

```python
from src.core.strategy import Strategy, register_strategy
from src.core.context import Context
from src.core.events import Event, EventType


@register_strategy("my_strategy")
class MyStrategy(Strategy):
    """策略类必须遵循以下约定"""

    name = "my_strategy"

    def __init__(self, params: Optional[Dict] = None) -> None:
        super().__init__(params)
        # 从 params 字典读取参数
        self.top_n: int = int(self.params.get("top_n", 5))
        # 启动即失败：参数合理性校验
        if self.top_n < 1:
            raise ValueError(f"top_n must be >= 1, got {self.top_n}")

    def on_init(self, context: Context) -> None:
        """初始化：获取数据库连接、注册定时器。"""
        self._db = context.get_db()
        context.add_timer("rebalance", "month_start")
        context.log("info", "策略初始化", top_n=self.top_n)

    def on_event(self, event: Event, context: Context) -> None:
        """统一事件处理：按 event.type 分发。"""
        if event.type is EventType.BAR:
            self._on_bar(event, context)
        elif event.type is EventType.TIMER and event.name == "rebalance":
            self._rebalance(context, event)

    def on_stop(self, context: Context) -> None:
        """策略停止清理。"""
        context.log("info", "策略停止")
```

### 3.2 生命周期

策略生命周期由 3 个回调组成：

| 回调 | 触发时机 | 调用次数 | 典型用途 |
|------|----------|----------|----------|
| `on_init(context)` | 引擎启动 | 1 次 | 获取 DB、注册定时器、预计算 |
| `on_event(event, context)` | 每个事件 | N 次 | 按 event.type 分发处理逻辑 |
| `on_stop(context)` | 引擎停止 | 1 次 | 清理资源、输出总结 |

### 3.3 参数规范

- 所有参数通过 `params: Dict` 字典传入，由 CLI `--param key=value` 指定
- 参数必须为基本类型：`int` / `float` / `bool` / `str`
- 在 `__init__` 中做参数合理性校验，**启动即失败**
- 参数命名清晰，避免单字母（`n` / `k` 等除外）

### 3.4 自动注册

使用 `@register_strategy(name)` 装饰器注册策略类到全局注册表 `_STRATEGY_REGISTRY`：

```python
@register_strategy("small_cap")
class SmallCapStrategy(Strategy):
    name = "small_cap"  # 必须与注册名一致
    ...
```

注册后可通过 `get_strategy_class("small_cap")` 获取策略类，`list_strategies()` 列出所有已注册策略名。

### 3.5 on_event 内部禁止事项

- `print()` 调试输出（使用 `context.log()` 代替）
- 起线程 / 进程
- 修改全局变量
- 读写文件
- 网络请求
- 持有不可序列化对象

## 4. 事件系统（EventType）

### 4.1 事件类型

8 种事件类型（继承 `str, Enum`，便于序列化）：

| EventType | 字符串 | 说明 | 触发时机 |
|-----------|--------|------|----------|
| `INIT` | "init" | 初始化事件 | 引擎启动，只推送一次 |
| `BAR` | "bar" | K线事件 | 每根 bar（日/分钟级） |
| `TICK` | "tick" | Tick 事件 | 高频可选 |
| `ORDER` | "order" | 订单状态变化 | 提交/成交/撤销/拒绝 |
| `TRADE` | "trade" | 成交回报 | 每次撮合成交 |
| `TIMER` | "timer" | 定时器事件 | 调仓日/开盘前/收盘后 |
| `ACCOUNT` | "account" | 账户资金变化 | 每日收盘后 |
| `STOP` | "stop" | 结束事件 | 引擎停止，只推送一次 |

### 4.2 关键事件类

#### BarEvent（K线事件，最常用）

```python
@dataclass
class BarEvent(Event):
    symbol: str          # 标的代码（主体字段，全市场模式下可能为空或首个 symbol）
    open: float          # 开盘价
    high: float          # 最高价
    low: float           # 最低价
    close: float         # 收盘价
    volume: float        # 成交量（股）
    amount: float        # 成交额（元）
    frequency: str       # 频率标识，默认 "1d"（日线）
    extra: dict          # 扩展字段（关键，详见 §6.2）
```

> **重要**：BarEvent 的 `extra` 字段是策略获取当日全市场数据的核心通道，详见 [§6.2](#62-barevent-携带的全市场数据)。

#### TimerEvent（定时器事件）

```python
@dataclass
class TimerEvent(Event):
    name: str   # 定时器名称（与 add_timer 注册时一致）
    rule: str   # 触发规则描述（仅用于日志）
```

#### TradeEvent（成交回报）

```python
@dataclass
class TradeEvent(Event):
    fill_id: str
    order_id: str
    symbol: str
    direction: str       # "buy" / "sell"
    volume: float
    price: float
    commission: float    # 佣金
    stamp_tax: float     # 印花税（仅卖出）
    transfer_fee: float  # 过户费
```

#### OrderEvent（订单状态变化）

```python
@dataclass
class OrderEvent(Event):
    order_id: str
    symbol: str
    direction: str       # "buy" / "sell" / "target"
    volume: float        # 委托数量
    filled_volume: float # 已成交数量
    avg_fill_price: float
    status: str          # pending/submitted/partial/filled/cancelled/rejected
    reason: Optional[str]  # 拒绝/撤销原因
```

### 4.3 定时器规则

通过 `context.add_timer(name, rule)` 注册定时器，支持以下规则：

| 规则 | 说明 |
|------|------|
| `month_start` | 每月第一个交易日 |
| `month_end` | 每月最后一个交易日 |
| `week_start` | 每周第一个交易日 |
| `daily_open` | 每日开盘 |
| `daily_close` | 每日收盘 |

## 5. 上下文接口（Context）

`Context` 是策略与引擎交互的唯一通道，封装 8 大职责。

> **数据获取相关接口的详细用法见 [§6. 数据获取接口](#6-数据获取接口)**。

### 5.1 数据访问（详见 §6）

```python
# 订阅标的（on_init 中调用）
context.subscribe(symbols: Union[str, List[str]]) -> None

# 查询历史 K 线（避免未来函数）
context.history(symbol: str, fields="close", count=100) -> Any
context.history_multi(symbols: List[str], fields="close", count=100) -> Any

# 获取已订阅标的
context.get_subscribed_symbols() -> List[str]

# 获取数据库连接（只读，用于查询市值/财务/股票池等）
context.get_db() -> Optional[DatabaseManager]
```

### 5.2 订单操作

```python
# 提交订单（主动式下单，vnpy 风格）
order_id = context.submit_order(
    symbol="600519.SH",
    direction="buy",          # "buy" / "sell" / "target"
    volume=100,               # 按数量下单
    # 或
    target_weight=0.1,        # 按目标权重下单（direction="target" 时使用）
    price_type="market",      # "market" / "limit" / "next_open" / "target_percent"
    price=None,               # 限价单价格（price_type="limit" 时使用）
    order_id=None,            # 可选，未指定则引擎自动生成
) -> str                      # 返回 order_id

# 撤销订单
context.cancel_order(order_id: str) -> bool
```

**下单方式说明**：

| 方式 | direction | 必填参数 | 说明 |
|------|-----------|----------|------|
| 按数量 | `"buy"` / `"sell"` | `volume` | 主动指定买卖数量 |
| 按目标权重 | `"target"` | `target_weight` | 引擎自动计算目标数量并转换为 buy/sell |

**价格类型说明**：

| price_type | 说明 |
|------------|------|
| `market` | 市价单（按当前 bar 收盘价撮合） |
| `limit` | 限价单（需指定 `price` 参数） |
| `next_open` | 次日开盘价撮合（避免未来函数） |
| `target_percent` | 目标权重调仓专用 |

### 5.3 持仓查询

```python
# 查询单个标的持仓
pos = context.get_position(symbol: str) -> Optional[Dict]
# 返回字段: {"quantity", "available", "avg_price", "market_price", "pnl", ...}
# - quantity:    总持仓数量
# - available:   可卖数量（T+1 后释放）
# - avg_price:   持仓均价
# - market_price: 当前市价

# 无持仓时返回 None

# 查询全部持仓
positions = context.get_positions() -> Dict[str, Dict]
# 返回: {symbol: 持仓字典}，无持仓时返回空 dict
```

### 5.4 账户查询

```python
account = context.get_account() -> Dict
# 返回字段:
# - cash:          可用现金
# - frozen:        冻结资金（Pending 订单占用）
# - market_value:  持仓市值
# - total:         总资产 = cash + frozen + market_value
# - pnl:           累计盈亏 = total - initial_cash
# - pnl_pct:       累计盈亏百分比 = pnl / initial_cash
# - daily_pnl:     当日盈亏
# - daily_pnl_pct: 当日盈亏百分比
```

### 5.5 定时器

```python

context.is_timer_due(name: str) -> bool
```

### 5.6 时间查询

```python
current_time = context.get_clock() -> datetime
# 回测模式返回 BarEvent.timestamp（模拟时间）
# 模拟盘/实盘返回墙钟时间
```

## 6. 数据获取接口

策略获取数据的**三种方式**，按优先级排列：

| 方式 | 接口 | 适用场景 | 是否含未来数据 |
|------|------|----------|----------------|
| 1. BarEvent 携带的全市场数据 | `event.extra["symbols_bars"]` | 当日全市场 OHLC 选股 | 否（仅当日） |
| 2. 历史K线查询 | `context.history()` / `context.history_multi()` | 计算技术指标（MA/RSI/ATR） | 否（严格切片） |
| 3. 数据库只读查询 | `context.get_db()` | 查询市值/财务/股票池/指数成分 | 需策略自行避免未来函数 |

### 6.1 数据获取方式总览

```python
def on_event(self, event: Event, context: Context) -> None:
    if event.type is EventType.BAR:
        # 方式 1：从 BarEvent 获取当日全市场数据
        symbols_bars = event.extra.get("symbols_bars", {})
        trade_date = event.extra.get("trade_date", "")

        # 方式 2：查询某只股票的历史 K 线（计算 MA 等指标）
        hist = context.history("600519.SH", fields=["close", "volume"], count=20)

        # 方式 3：从数据库查询市值/财务等数据
        db = context.get_db()
        if db is not None:
            mkt = db.get_stock_mktvalue(
                stock_codes=["600519.SH"],
                start_date="2024-01-01",
                end_date=trade_date,
            )
```

### 6.2 BarEvent 携带的全市场数据

**这是策略获取当日全市场行情的主要方式**，用于全市场选股、调仓等场景。

#### 数据结构

```python
# BarEvent.extra 字段内容
extra = {
    "trade_date": "2024-06-28",                # 当前交易日（YYYY-MM-DD）
    "symbols_bars": {                           # 全市场当日 bar 字典
        "600000.SH": {                          # key: 股票代码
            "open": 10.5,                       # 开盘价
            "high": 10.8,                       # 最高价
            "low": 10.3,                        # 最低价
            "close": 10.6,                      # 收盘价
            "volume": 12345678.0,               # 成交量（股）
            "amount": 130000000.0,              # 成交额（元）
            "pre_close": 10.4,                  # 昨收价
            "vwap": 10.55,                      # 成交均价
            "suspend_flag": None,               # 停牌标志
            # ... 其他 t_stock_daily 字段
        },
        "000001.SZ": {...},
        # ... 全市场所有股票
    }
}
```

#### 使用示例

```python
def on_event(self, event: Event, context: Context) -> None:
    if event.type is not EventType.BAR:
        return

    trade_date = event.extra.get("trade_date", "")
    symbols_bars = event.extra.get("symbols_bars", {})

    # 示例 1：获取所有可交易股票（排除停牌）
    tradable = [
        sym for sym, bar in symbols_bars.items()
        if bar.get("volume", 0) > 0 and not bar.get("suspend_flag")
    ]

    # 示例 2：按收盘价选股
    sorted_syms = sorted(
        symbols_bars.items(),
        key=lambda x: x[1]["close"],
    )

    # 示例 3：获取某只股票当日行情
    bar = symbols_bars.get("600519.SH")
    if bar:
        close = bar["close"]
        volume = bar["volume"]
```

#### 字段来源

`symbols_bars` 字段来源于 `t_stock_daily` 表，由引擎在每日开盘前从数据库加载并注入 `BarEvent.extra`。字段与数据库表列名一致。

### 6.3 context.history() 历史K线查询

用于计算技术指标（MA/RSI/MACD/ATR 等），严格避免未来函数。

#### 接口签名

```python
# 查询单个标的的历史 K 线
context.history(
    symbol: str,                              # 标的代码，如 "600519.SH"
    fields: Union[str, List[str]] = "close",  # 字段名或字段列表
    count: int = 100,                         # 返回最近 N 根 K 线
) -> Any
# 返回：单字段时 List[float]；多字段时结构化对象（dict 或 DataFrame）

# 批量查询多个标的的历史 K 线
context.history_multi(
    symbols: List[str],                       # 标的代码列表
    fields: Union[str, List[str]] = "close",
    count: int = 100,
) -> Any
# 返回：dict[symbol, ...] 结构
```

#### 可用字段

| 字段 | 说明 |
|------|------|
| `open` | 开盘价 |
| `high` | 最高价 |
| `low` | 最低价 |
| `close` | 收盘价 |
| `volume` | 成交量 |
| `amount` | 成交额 |
| `pre_close` | 昨收价 |
| `vwap` | 成交均价 |

#### 使用示例

```python
def _calc_ma(self, context: Context, symbol: str, n: int = 20) -> float:
    """计算 N 日均线。"""
    closes = context.history(symbol, fields="close", count=n)
    if not closes or len(closes) < n:
        return 0.0
    return sum(closes) / len(closes)
```

#### 切片规则（避免未来函数）

`history()` 返回当前时间点**之前**（含当前 bar）的历史数据，绝不包含未来数据。

例如：on_bar 处理 2024-06-28 的 BarEvent 时，`context.history("600519.SH", count=5)` 返回 2024-06-24 ~ 2024-06-28 的数据（含当日）。

```python
def on_init(self, context: Context) -> None:
    self._db = context.get_db()

def _select_by_market_cap(self, trade_date: str, top_n: int) -> List[str]:
    """按总市值选股（小市值策略示例）。"""
    if self._db is None:
        return []
```

## 7. 风控层（A 股专用）

### 7.1 三层风控架构

A 股风控由 `build_ashare_risk_manager()` 构造，包含 11 个 Check，分三层：

| 层级 | Check | 说明 | 默认参数 |
|------|-------|------|----------|
| **Layer 1 法定风控（必执行）** | `LimitUpCheck` | 涨停不买 | 主板 10%、双创 20% |
| | `LimitDownCheck` | 跌停不卖 | 主板 10%、双创 20% |
| | `STFilterCheck` | ST / *ST / 退市股过滤 | - |
| | `NewStockCheck` | 新股过滤（上市 < 60 天） | 60 天 |
| | `SuspendCheck` | 停牌过滤 | - |
| | `TPlusOneCheck` | T+1 可卖量检查 | - |
| **Layer 2 订单级（必执行）** | `MaxOrderQtyCheck` | 单笔最大下单量 | 100 万股 |
| | `LotSizeCheck` | lot_size 整数倍 | 科创板 200 / 其他 100 |
| **Layer 3 组合级（可选）** | `MaxPositionPctCheck` | 单持仓仓位上限 | 30% |
| | `MaxPositionsCheck` | 持仓数量上限 | 10 只 |
| | `DailyStopLossCheck` | 日亏急停 | -5% |

### 7.2 策略层不再实现风控

以下风控逻辑**由 `RiskManager` 自动处理**，策略层不应实现：

- 止损 / 止盈 / 动态止盈 → 委托给 `DailyStopLossCheck`
- 涨跌停 / ST / 新股 / 停牌 / T+1 → 由法定风控自动处理

策略层只需关注**选股信号与调仓决策**，市场趋势过滤等业务逻辑可在 `on_event` 中表达（如 `close > MA(60)` 才下单）。

### 7.3 风控参数调整

风控参数通过 CLI 传递（详见 CLI 使用说明文档），策略代码无需关心。策略开发者只需确保选股逻辑符合 A 股市场约束（见 §8）。

## 8. A 股市场约束

### 8.1 必须遵守的过滤规则

所有 A 股策略必须遵守以下过滤规则（由 `build_ashare_risk_manager()` 默认启用）：

| 规则 | 说明 |
|------|------|
| ST 过滤 | 排除 ST / *ST / 退市股 |
| 新股过滤 | 排除上市不满 60 天的股票 |
| 涨跌停过滤 | 主板 10%、创业板/科创板 20%；涨停不买、跌停不卖 |
| 停牌过滤 | 停牌股不参与交易 |
| T+1 规则 | 当日买入次日才能卖出 |
| 手数限制 | 科创板 200 股一手，其他 100 股一手 |
| 单笔上限 | 单笔最大下单量 100 万股 |
| 仓位上限 | 单持仓不超过总资产 30% |
| 持仓数量 | 最多持有 10 只股票 |
| 日亏急停 | 日亏损超过 5% 停止交易 |

## 9. 回测数据范围要求

### 9.1 完整回测

进行完整回测（非功能性快速验证）时，**必须使用最近 5 年数据**进行测试。

### 9.2 功能性验证

短区间（1-3 个月）仅用于功能性验证，不能作为策略效果评估依据。

### 9.3 数据完整性

- 回测前确保数据库中相关日期范围内的数据已同步完整
- 回测引擎在数据缺失时会报错退出（不使用 mock 数据）
- 估值数据和财务数据需同步完整，否则策略可能降级为纯技术面选股
- 市值数据需同步完整，小市值策略依赖此表选股

### 9.4 策略数据依赖声明

每个策略在 `策略路径.md` 中必须声明数据依赖（见 [§10](#10-策略路径md-模板)），便于回测前检查数据完整性。常见数据依赖：

| 数据类型 | 获取方式 | 典型用途 |
|----------|----------|----------|
| 日K行情 | `BarEvent.extra["symbols_bars"]` | 选股、技术指标 |
| 历史K线 | `context.history()` | MA/RSI/ATR 计算 |
| 市值数据 | `db.get_stock_mktvalue()` | 小市值选股、市值加权 |
| 财务数据 | `db.get_t_finance_prime()` / `get_finance_deriv()` | 基本面过滤 |

## 11. 完整策略模板

新策略开发时，复制以下模板并替换 `<...>` 占位符：

```python
"""
<策略名> - <策略中文名>
====================================================================

策略逻辑：
    <一句话描述策略逻辑>

数据来源：
    - 当日行情：BarEvent.extra["symbols_bars"]（全市场 OHLC）
    - 历史K线：context.history()（计算 MA 等指标）
    - <策略专用数据>：db.get_xxx()（通过 context.get_db() 只读查询）

参数：
    - <param1>: <说明>（默认 <value>）
    - <param2>: <说明>（默认 <value>）

用法：
    python main.py backtest -s <策略名> \\
        --start-date 2024-01-01 --end-date 2024-12-31 \\
        --param <param1>=<value>
"""

import logging
from typing import Any, Dict, List, Optional

from src.core.context import Context
from src.core.events import Event, EventType
from src.core.strategy import Strategy, register_strategy

logger = logging.getLogger(__name__)


@register_strategy("<策略名>")
class <StrategyName>Strategy(Strategy):
    """<策略中文名>。

    <策略逻辑简述>

    Parameters
    ----------
    <param1> : int
        <说明>（默认 <value>）
    <param2> : str
        <说明>（默认 <value>）
    """

    name = "<策略名>"

    def __init__(self, params: Optional[Dict] = None) -> None:
        super().__init__(params)
        # 从 params 字典读取参数
        self.<param1>: int = int(self.params.get("<param1>", <default>))
        self.<param2>: str = str(self.params.get("<param2>", <default>))

        # 参数校验（启动即失败）
        if self.<param1> < 1:
            raise ValueError(f"<param1> must be >= 1, got {self.<param1>}")

        # 内部状态
        self._db: Any = None
        self._last_rebalance_date: str = ""

    # ------------------------------------------------------------------
    # 生命周期回调
    # ------------------------------------------------------------------

    def on_init(self, context: Context) -> None:
        """初始化：获取数据库连接，注册定时器。"""
        self._db = context.get_db()
        context.add_timer("rebalance", self.<param2>)
        context.log("info", "<策略名>初始化", <param1>=self.<param1>)

    def on_event(self, event: Event, context: Context) -> None:
        """统一事件处理：按 event.type 分发。"""
        if event.type is EventType.BAR and not self._last_rebalance_date:
            # 首个 BarEvent：触发首次建仓
            self._rebalance(context, event)
            return

        if event.type is EventType.TIMER and event.name == "rebalance":
            self._rebalance(context, event)

    def on_stop(self, context: Context) -> None:
        """策略停止。"""
        context.log("info", "<策略名>停止")

    # ------------------------------------------------------------------
    # 核心逻辑
    # ------------------------------------------------------------------

    def _rebalance(self, context: Context, event: Event) -> None:
        """执行调仓。"""
        trade_date = self._get_trade_date(event)
        if not trade_date:
            return

        # 避免同一交易日重复调仓
        if trade_date == self._last_rebalance_date:
            return

        # 获取当日全市场股票列表
        symbols_bars = self._get_symbols_bars(event)
        if not symbols_bars:
            return

        # 选股逻辑
        target_symbols = self._select(trade_date, list(symbols_bars.keys()))
        if not target_symbols:
            context.log("warning", "无合格目标股票", trade_date=trade_date)
            return

        # 等权配置
        weight = 1.0 / self.<param1> if self.<param1> > 0 else 0.0
        for sym in target_symbols:
            context.submit_order(
                symbol=sym,
                direction="target",
                target_weight=weight,
                price_type="market",
            )

        # 清仓不在目标池的持仓
        positions = context.get_positions()
        for sym in positions:
            if sym not in target_symbols:
                context.submit_order(
                    symbol=sym,
                    direction="target",
                    target_weight=0.0,
                    price_type="market",
                )

        self._last_rebalance_date = trade_date
        context.log("info", "调仓完成",
                    trade_date=trade_date, target_count=len(target_symbols))

    # ------------------------------------------------------------------
    # 辅助方法
    # ------------------------------------------------------------------

    @staticmethod
    def _get_trade_date(event: Event) -> str:
        """从事件中提取交易日字符串。"""
        extra = getattr(event, "extra", None)
        if extra and isinstance(extra, dict):
            return extra.get("trade_date", "")
        return ""

    @staticmethod
    def _get_symbols_bars(event: Event) -> Dict[str, Any]:
        """从事件中获取全市场当日 bar 字典。"""
        extra = getattr(event, "extra", None)
        if extra and isinstance(extra, dict):
            return extra.get("symbols_bars", {})
        return {}

    def _select(self, trade_date: str, candidates: List[str]) -> List[str]:
        """选股逻辑（示例：按总市值升序取前 N）。"""
        if self._db is None:
            return candidates[:self.<param1>]

        # 查询当日市值数据（注意：截止 trade_date，避免未来函数）
        df = self._db.get_stock_mktvalue(
            stock_codes=candidates,
            start_date=trade_date,
            end_date=trade_date,
        )
        if df.empty:
            return candidates[:self.<param1>]

        # 按总市值升序排序，取前 N 只
        df = df.sort_values("tot_mv").head(self.<param1>)
        return df["stock_code"].tolist()
```
