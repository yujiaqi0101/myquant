# 策略元调度：市场状态识别 × 策略匹配

## 一、核心思路

**现状问题**：我们有16个策略，各自适应不同市场环境，但当前是"全天候运行"——牛熊震荡一刀切，导致：
- 趋势策略在震荡市磨损（如ETF轮动V2在2021-2022年夏普骤降）
- 反转策略在趋势市踏空（如负反馈反转在单边上涨中频繁止损）
- 好策略用错时段 = 差策略

**解决思路**：增加一层**市场状态识别器**，实时判断当前处于什么市，再从策略池中选择最匹配的策略组合运行。

```
传统: 市场数据 → 策略 → 交易信号
改进: 市场数据 → 状态识别 → 策略选择 → 匹配策略 → 交易信号
```

## 二、市场状态如何量化？（三层指标体系）

### 第一层：趋势状态（牛/熊/震荡）
| 指标 | 计算方式 | 判断逻辑 |
|------|---------|---------|
| MA斜率 | 沪深300的20/60日均线斜率 | 斜率>阈值=趋势市，<阈值=震荡市 |
| ADX | 平均趋向指数(14日) | ADX>25=强趋势，<20=无趋势 |
| MACD趋势 | DIF与DEA关系+零轴位置 | 零轴上方金叉=牛市，零轴下方死叉=熊市 |
| 价格位置 | 收盘价 vs 布林带上下轨 | 触上轨=强趋势，在中轨间震荡=震荡市 |

### 第二层：波动状态（高波/低波）
| 指标 | 计算方式 | 判断逻辑 |
|------|---------|---------|
| 已实现波动率 | 沪深300 20日收益率标准差×√252 | >历史75分位=高波，<25分位=低波 |
| 波动率变化 | 短期(5日)/长期(20日)波动率比值 | >1.5=波动放大（恐慌期），<0.7=波动收缩 |
| ATR比率 | ATR(14)/收盘价 | 极端高=危机模式，极端低=沉寂期 |

### 第三层：市场宽度（普涨/分化/普跌）
| 指标 | 计算方式 | 判断逻辑 |
|------|---------|---------|
| 涨跌比 | 全市场上涨家数/下跌家数 | >2=普涨，<0.5=普跌，中间=分化 |
| 均线上方比例 | 收盘价>60日均线个股占比 | >70%=强势，<30%=弱势 |
| 行业一致性 | 申万31个行业指数涨跌方向一致性 | 高一致性=系统性行情，低=结构性 |

### 综合状态判断（6种典型市场环境）

| 状态 | 趋势 | 波动 | 宽度 | 典型特征 |
|------|------|------|------|---------|
| 🔴 强牛市 | 上升 | 低~中 | 普涨 | 2019Q1, 2024Q4 |
| 🟠 震荡上行 | 上升 | 中 | 分化 | 2020H2, 2025H1 |
| 🟡 宽幅震荡 | 无方向 | 高 | 分化 | 2021, 2023 |
| 🟢 窄幅震荡 | 无方向 | 低 | 分化 | 2019Q3, 2024Q2 |
| 🔵 震荡下行 | 下降 | 中 | 分化 | 2022H1 |
| ⚫ 恐慌熊市 | 下降 | 极高 | 普跌 | 2022Q1, 2020Q1 |

- **反转型策略**（6个反转）→ 震荡市是主场，趋势市反复止损

- **混合型策略**（攻防轮动/成交量异动）→ 适应面广但弹性小

## 四、实现方案（三种递进方案）

### 方案A：规则引擎（简单可控）
- 用固定阈值判断市场状态（如HS300 MA20斜率+ADX+波动率分位数）
- 查表匹配策略，每个状态选2-3个策略等权组合
- **优点**：可解释、易调试、回测方便
- **缺点**：阈值需要经验设定，状态切换可能滞后

### 方案B：隐马尔可夫模型 HMM（数据驱动）
- 用2-3个隐状态拟合市场，输入波动率+收益率+宽度指标
- 模型自动学习状态转移概率，无需人工阈值
- **优点**：自适应、概率输出（如70%概率震荡+30%概率牛市）
- **缺点**：状态含义需要事后解释，过拟合风险

### 方案C：滚动回测动态权重（最实用）
- 不做硬性状态判断，而是用近期指标给每个策略动态打分
- 每期计算：趋势强度分、波动分、宽度分 → 映射为各策略权重
- 权重连续变化而非0/1切换，避免状态跳变导致的大幅调仓
- **优点**：过渡平滑、不会因为误判全错
- **缺点**：映射关系仍需设计

### 推荐：方案C为主 + 方案A辅助
- 方案C做权重平滑分配，方案A做硬性风控（如恐慌熊市直接降仓）
- 这样既有灵活性又有安全垫

## 五、需要补充考虑的问题

### 1. 状态识别的滞后性
- 所有指标都是"向后看"的，市场拐点时最危险
- **对策**：加入前瞻指标（如融资余额变化、北向资金流向、期权PCR等情绪指标）

### 2. 策略切换成本
- 从趋势策略切到反转策略意味着换仓，实盘有冲击成本
- **对策**：权重渐变而非跳变，设最小持仓周期

### 3. 误判代价不对称
- 把震荡市误判为牛市 → 趋势策略磨损，可承受
- 把牛市误判为震荡市 → 反转策略反复止损踏空，代价更大
- **对策**：宁可多给趋势策略一点权重，错过好于做错

### 4. 行业级别的状态识别
- 除了大盘状态，不同行业可能处于不同周期
- 如2023年：AI板块牛市，地产板块熊市
- **对策**：大盘状态控制总仓位，行业状态控制行业暴露

### 5. 样本外验证
- 状态识别器本身也有参数，需要防止过拟合
- **对策**：用2019-2022训练，2023-2025验证；或滚动窗口

### 6.2 市场状态识别算法

**输入**：沪深300指数日K线（收盘价、收益率）

**Step 1 — 趋势得分（trend_score）**

4个子指标滚动分位数归一化后加权：

```
trend_score = 0.30 × qnorm(MA20斜率)
            + 0.20 × qnorm(MA60斜率)
            + 0.20 × qnorm(ADX)
            + 0.30 × MACD布林复合分
```

各子指标计算：
- **MA20斜率** = `HS300收盘价.rolling(20).mean().pct_change(5)` — 均线5日变化率
- **MA60斜率** = `HS300收盘价.rolling(60).mean().pct_change(5)`
- **ADX** = 14日平均趋向指数
- **MACD布林复合分** = `(DIF>DEA)×0.5 + (价格>布林中轨)×0.3 + (DIF>0)×0.2`，取0~1连续值

**qnorm(分位数归一化)**：`s.rolling(252).rank(pct=True)`，将任意指标映射到[0,1]，消除绝对阈值依赖

**Step 2 — 波动得分（vol_score）**

```
vol_score = 0.70 × qnorm(已实现波动率)
          + 0.30 × 波动放大标志
```

- **已实现波动率** = `收益率.rolling(20).std() × √252`
- **波动放大标志** = `短期波动率(5日)/长期波动率(20日) > 1.3`，布尔值转float

**Step 3 — 宽度得分（breadth_score）**

```
breadth_score = 0.60 × qnorm(策略上涨比例)
              + 0.40 × qnorm(大盘上涨5日均值)
```

- **策略上涨比例** = 16个策略当日收益率>0的数量 / 16
- **大盘上涨5日均值** = `(HS300收益率>0).rolling(5).mean()`

**Step 4 — 状态判定（6种）**

```
if trend_score > 0.60 and breadth_score > 0.50:
    状态 = "强牛市"
elif 0.45 < trend_score ≤ 0.60 and 当前默认窄幅震荡:
    状态 = "震荡上行"
elif 0.35 ≤ trend_score ≤ 0.65 and vol_score > 0.55:
    状态 = "宽幅震荡"
elif 0.30 ≤ trend_score < 0.45 and 当前默认窄幅震荡:
    状态 = "震荡下行"
elif trend_score < 0.30 and (vol_score > 0.50 or breadth_score < 0.30):
    状态 = "恐慌熊市"
else:
    状态 = "窄幅震荡"（默认兜底）
```

**Step 5 — 拐点预警（inflection）**

```
拐点 = (波动放大比>1.5 且 宽度<0.35)
    or (连续3日下跌 且 波动放大比>1.2)
```

拐点时趋势型策略权重额外打5折。

### 6.3 策略类型 × 市场状态评分矩阵

每个市场状态下，4种策略类型各有一个基础适配分（0~1）：

| 市场状态 | trend | reversal | hybrid | defensive |
|---------|-------|----------|--------|-----------|
| 强牛市 | 1.00 | 0.15 | 0.60 | 0.10 |
| 震荡上行 | 0.75 | 0.30 | 0.80 | 0.30 |
| 宽幅震荡 | 0.25 | 0.90 | 0.60 | 0.50 |
| 窄幅震荡 | 0.15 | 0.70 | 0.50 | 0.60 |
| 震荡下行 | 0.10 | 0.50 | 0.30 | 0.80 |
| 恐慌熊市 | 0.00 | 0.25 | 0.15 | 0.90 |

**设计原则**：
- 牛市趋势=1.0，恐慌防御=0.9 — 极端状态极端分配
- 反转在宽幅震荡最强(0.9)，防御在恐慌熊市最强(0.9)
- 混合在震荡上行最突出(0.8)

### 6.4 类型溢价（TYPE_PREMIUM）

不同类型在长期统计上对组合的贡献不同，用溢价系数调整：

| 类型 | 溢价系数 | 理由 |
|------|---------|------|
| trend | **1.3** | 趋势策略在正确时段收益弹性最大，值得给更高权重 |
| hybrid | 1.1 | 混合型适应性广但弹性中等 |
| reversal | 1.0 | 反转策略是基本盘，不加不减 |
| defensive | 0.8 | 防御策略主要是压回撤，收益贡献有限 |

### 6.5 权重计算全流程

**Step 1 — 原始权重**

对每个交易日t的每个策略i：
```
raw_weight[i] = STATE_TYPE_SCORE[状态][策略i的类型] × TYPE_PREMIUM[策略i的类型]

如果当日触发拐点预警 且 策略类型==trend:
    raw_weight[i] *= 0.5  （趋势策略额外打5折）
```

**Step 2 — 归一化**

```
target_weight[i] = raw_weight[i] / sum(raw_weight[所有策略])
```

确保权重和为1。

**Step 3 — 反转上限约束**

```
if sum(反转型权重) > 60%:
    反转型权重整体缩放至60%
    非反转型权重整体缩放至40%（等比分配）
```

防止反转策略过度集中（6个反转策略数量占比38%，不加约束时权重可达70%+）。

**Step 4 — EMA平滑**

```
smooth_weight[t] = EMA(target_weight, span=20)
```

- 使用指数移动平均平滑权重变化，避免状态跳变导致的大幅调仓
- 平滑后重新归一化（`w[i] = max(w[i], 0)` 然后 `w /= w.sum()`）
- 回测对比了span=5/10/15/20，最优为span=20

**Step 5 — 仓位控制（可选叠加）**

5种仓位控制方案：

| 方案 | 实现 | 效果 |
|------|------|------|
| 无仓位控制 | position=1.0（始终满仓） | 基线 |
| 2%现金预留 | position=0.98 | 年化降0.6%，夏普不变 |
| 轻量仓位控制 | 震荡下行=0.7, 恐慌熊市=0.4, 其余=1.0 | 回撤改善0.5%，年化降1.9% |
| 轻量+2%预留 | 轻量仓位 × 0.98 | 组合效果 |
| 全仓位控制 | 强牛=1.0/震荡上=0.85/宽幅=0.65/窄幅=0.55/震荡下=0.4/恐慌=0.2 | 代价太大，夏普降0.21 |

仓位系数直接乘到组合日收益率上：`port_ret = (策略权重 × 策略收益率).sum() × position`

### 6.6 组合净值计算

```
日收益率 = sum(smooth_weight[t-1] × 策略收益率[t]) × position[t-1]
净值 = cumprod(1 + 日收益率)
```

注意权重和仓位都用**前一天**的值（shift(1)），确保无未来函数。

### 6.7 实盘约束层（在底层策略中实现）

4个约束在nav生成阶段（live_constraints_backtest.py）已嵌入，不在调度层处理：

| 约束 | 实现位置 | 逻辑 | 影响 |
|------|---------|------|------|
| 2%现金预留 | 调度层×0.98 或 底层仓位上限0.98 | 总仓位不超过98%，留手续费 | 极小 |
