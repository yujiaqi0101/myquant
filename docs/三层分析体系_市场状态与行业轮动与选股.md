
# 三层分析体系：市场状态识别 → 行业轮动 → 行业内选股

## 体系总览

```
┌─────────────────────────────────────────────────────────────────┐
│                      第三层：行业内选股                          │
│  输入：目标行业内的候选股票池（448只 × 行业标签）                  │
│  引擎：16个底层策略按类型匹配市场状态，输出个股打分与持仓          │
│  产出：每日持仓列表（15只）                                      │
├─────────────────────────────────────────────────────────────────┤
│                      第二层：行业轮动                            │
│  输入：26个申万一级行业ETF的K线数据                              │
│  引擎：行业动量评分 + 行业趋势确认 + 行业波动过滤                 │
│  产出：Top5目标行业 + 行业权重                                   │
├─────────────────────────────────────────────────────────────────┤
│                      第一层：市场状态识别                        │
│  输入：沪深300指数K线、全市场波动率、市场宽度                     │
│  引擎：趋势得分 + 波动得分 + 宽度得分 → 6种状态                  │
│  产出：当前市场状态标签 + 仓位系数 + 策略类型权重指引              │
└─────────────────────────────────────────────────────────────────┘

数据流方向：自上而下
  第一层 → 确定市场环境 → 仓位系数 + 策略类型偏好
  第二层 → 确定行业暴露 → Top5行业 + 行业间权重
  第三层 → 确定个股持仓 → 每个行业内选3只，共15只
```

**核心设计原则**：
- **信号层与选股层分离**：行业信号来自行业ETF（代表整个行业走势，不受448只覆盖度限制），选股在448只股票池内执行
- **三层独立可验证**：每层都有独立的回测基线，可以单独评估增量贡献
- **由粗到细**：先判断大环境（是否该参与），再选方向（哪些行业），最后选标的（具体个股）

## 第一层：市场状态识别

### 1.1 目的

回答"当前市场处于什么环境"，决定：
1. **仓位水平**：是否需要降低整体仓位避险
2. **策略风格偏好**：趋势型/反转型/防御型策略的相对权重
3. **行业轮动参数调整**：牛市可以更激进集中，熊市需要分散防御

### 1.2 指标体系（三维度 × 8个指标）

#### 维度A：趋势状态

| # | 指标名称 | 计算方式 | 判断逻辑 |
|---|---------|---------|---------|
| A1 | MA20斜率 | `HS300.rolling(20).mean().pct_change(5)` | >0.01=强上升，<-0.01=强下降，中间=震荡 |
| A2 | MA60斜率 | `HS300.rolling(60).mean().pct_change(5)` | 中期趋势方向确认 |
| A3 | ADX(14) | 14日平均趋向指数 | >25=强趋势，<20=无趋势 |
| A4 | MACD布林复合分 | `(DIF>DEA)×0.5 + (价格>布林中轨)×0.3 + (DIF>0)×0.2` | 连续0~1，越高越趋势 |

**趋势得分合成**：
```
trend_score = 0.30 × qnorm(A1) + 0.20 × qnorm(A2) + 0.20 × qnorm(A3) + 0.30 × A4
```
其中 `qnorm(x) = x.rolling(252).rank(pct=True)`，映射到[0,1]分位数

#### 维度B：波动状态

| # | 指标名称 | 计算方式 | 判断逻辑 |
|---|---------|---------|---------|
| B1 | 已实现波动率 | `HS300收益率.rolling(20).std() × √252` | >历史75分位=高波，<25分位=低波 |
| B2 | 波动放大比 | `短期波动率(5日) / 长期波动率(20日)` | >1.5=波动急升（恐慌信号），<0.7=波动收缩 |

**波动得分合成**：
```
vol_score = 0.70 × qnorm(B1) + 0.30 × (B2 > 1.3).astype(float)
```

#### 维度C：市场宽度

| # | 指标名称 | 计算方式 | 判断逻辑 |
|---|---------|---------|---------|
| C1 | 上涨策略比例 | `当日16策略中收益率>0的数量 / 16` | >0.7=普涨，<0.3=普跌 |
| C2 | 大盘上涨5日均值 | `(HS300收益率>0).rolling(5).mean()` | 近5日上涨天数占比 |

**宽度得分合成**：
```
breadth_score = 0.60 × qnorm(C1) + 0.40 × qnorm(C2)
```

### 1.3 状态判定规则

```
if trend_score > 0.60 and breadth_score > 0.50:
    状态 = "强牛市"          # 🔴 趋势强 + 普涨
elif 0.45 < trend_score ≤ 0.60 and vol_score < 0.55:
    状态 = "震荡上行"        # 🟠 趋势偏强 + 波动可控
elif 0.35 ≤ trend_score ≤ 0.65 and vol_score > 0.55:
    状态 = "宽幅震荡"        # 🟡 趋势不明 + 波动大
elif 0.30 ≤ trend_score < 0.45 and vol_score < 0.55:
    状态 = "震荡下行"        # 🔵 趋势偏弱 + 波动可控
elif trend_score < 0.30 and (vol_score > 0.50 or breadth_score < 0.30):
    状态 = "恐慌熊市"        # ⚫ 趋势极弱 + 恐慌信号
else:
    状态 = "窄幅震荡"        # 🟢 默认兜底
```

### 1.4 拐点预警机制

拐点是市场从一种状态急速切换到另一种的危险期，策略最容易出错。

```
触发条件（任一满足即预警）：
  ① 波动放大比 > 1.5 且 宽度得分 < 0.35
  ② 连续3日HS300下跌 且 波动放大比 > 1.2

预警动作：
  - 趋势型策略权重 × 0.5（额外打5折）
  - 行业轮动持仓数从每行业3只扩展到5只（分散风险）
```

### 1.5 各状态下的操作指引

| 市场状态 | 仓位系数 | 策略偏好 | 行业轮动参数 | 行为特征 |
|---------|---------|---------|------------|---------|
| 🔴 强牛市 | 1.0 | 趋势型×1.3 | Top5×3只，动量权重为主 | 集中进攻，让利润奔跑 |
| 🟠 震荡上行 | 1.0 | 混合型×1.1 | Top5×3只，趋势确认加权 | 均衡配置，偏进攻 |
| 🟡 宽幅震荡 | 0.85 | 反转型×1.0 | Top5×3只，反转保护开启 | 短周期操作，严止损 |
| 🟢 窄幅震荡 | 0.85 | 防御型×0.8 | Top8×2只，更分散 | 低频调仓，等突破 |
| 🔵 震荡下行 | 0.7 | 防御型×0.8 | Top5×3只→Top8×3只 | 防守为主，降低暴露 |
| ⚫ 恐慌熊市 | 0.4 | 防御型×0.8 | 降仓至30%，Top3×2只 | 极端避险，保留火种 |

## 第二层：行业轮动

### 2.1 目的

回答"当前哪些行业值得关注"，决定资金在行业间的分配。核心思路是**行业比个股更有动量惯性**——行业趋势一旦形成，持续性强于个股，且ETF信号覆盖全行业不受个股样本限制。

### 2.2 架构：信号层（ETF）与选股层（448只股票）分离

```
信号层（行业ETF K线）                    选股层（448只股票）
  26个申万一级行业ETF                      448只 × 申万行业分类
  │                                       │
  ├─→ 行业动量评分                         ├─→ 行业内因子打分
  ├─→ 行业趋势确认                         ├─→ 行业内策略选股
  └─→ 行业波动过滤                         └─→ 行业内持仓构建
  │                                       │
  └─────────── 行业选择 + 选股 ────────────┘
                     │
              最终持仓：Top5行业 × 每行业3只 = 15只
```

**为什么分离**：
- 448只股票覆盖30个行业，但行业内数量差异大（银行29只 vs 石油石化3只）
- 直接用448只构建"行业指数"会因样本偏差导致行业信号失真
- 行业ETF代表整个行业的资金流向和价格趋势，是更纯净的行业信号源

### 2.4 行业评分算法（三维复合）

#### 维度1：行业动量（权重0.50）

行业动量是最强信号源，回测证明纯行业60日动量评分的夏普已达1.42，与综合评分1.48仅差0.06。

```
行业动量得分[ind] = w1 × qnorm(ETF收益率20日[ind])
                  + w2 × qnorm(ETF收益率60日[ind])
                  + w3 × qnorm(ETF收益率5日[ind])

权重：w1=0.40, w2=0.40, w3=0.20
```

- **20日动量**：中期趋势强度，主信号
- **60日动量**：长期趋势确认，防止追逐短期噪音
- **5日动量**：短期加速度，捕捉趋势启动

#### 维度2：行业趋势确认（权重0.30）

```
趋势确认分[ind] = 0.50 × (ETF价格 > ETF_MA20[ind]).astype(float)
                + 0.30 × (ETF_MA20斜率[ind] > 0).astype(float)
                + 0.20 × (ETF_ADx14[ind] > 20).astype(float)
```

- 价格在均线上方 → 行业处于上升趋势
- 均线斜率为正 → 趋势正在加速
- ADX>20 → 趋势明确而非震荡

**作用**：过滤掉动量高但趋势已衰竭的行业（如反弹末期的行业）

#### 维度3：行业波动过滤（权重0.20）

```
波动过滤分[ind] = qnorm(-1 × ETF_20日波动率[ind])
```

取**负号**：波动越低得分越高。原因：
- 低波动行业更稳定，趋势延续性更好
- 高波动行业容易假突破，轮动信号不可靠
- 牛市中低波动行业通常是正在积蓄力量的行业（后续爆发力强）

#### 综合评分

```
行业综合分[ind] = 0.50 × 动量得分[ind]
                + 0.30 × 趋势确认分[ind]
                + 0.20 × 波动过滤分[ind]
```

**排序规则**：按综合分降序排列，取Top N行业

### 2.5 行业选择参数

| 参数 | 默认值 | 牛市值 | 震荡值 | 熊市值 |
|------|--------|--------|--------|--------|
| 选几个行业 | Top5 | Top5 | Top8 | Top3 |
| 每行业几只 | 3只 | 3只 | 2只 | 2只 |
| 总持仓数 | 15只 | 15只 | 16只 | 6只 |

**回测最优参数**：Top5行业 × 每行业3只 = 15只持仓

回测对比：

| 方案 | 年化 | 夏普 | 回撤 | 卡玛 |
|------|------|------|------|------|
| Top3×3 | 37.0% | 1.23 | -44.0% | 0.84 |
| **Top5×3** | **38.0%** | **1.48** | **-24.4%** | **1.56** |
| Top5×2 | 36.7% | 1.31 | -26.2% | 1.40 |
| Top5×5 | 30.7% | 1.28 | -24.4% | 1.26 |
| Top8×3 | 26.8% | 1.22 | -24.8% | 1.08 |
| Top10×3 | 24.1% | 1.17 | -21.5% | 1.12 |
| 基线全市场30只 | 25.7% | 0.96 | -31.5% | 0.82 |

**关键发现**：
- Top5×3是最优平衡点——集中度足够产生超额收益，分散度足以控制回撤
- Top3太集中，回撤-44%不可接受
- Top8/10太分散，趋近于全市场选股基线
- 行业等权 vs 行业评分权重：Top5×3时两者完全一致（说明关键是行业选择而非行业内权重分配）

### 2.6 行业间权重分配

**默认方案：等权分配**

Top5行业中，每个行业分配总仓位的1/5 = 20%。

**原因**：
- 回测中行业等权与行业评分加权的Top5×3方案结果完全一致（夏普都是1.48）
- 说明行业选择（进不进Top5）远比行业权重（进了之后分多少）重要
- 等权更简单、更稳健，避免评分权重因参数敏感导致过拟合

**仅在以下情况使用非等权**：
- 第一层识别为强牛市 → 按行业综合分加权（前2名行业各25%，后3名各16.7%）
- 第一层识别为恐慌熊市 → 等权但总仓位降低至40%

### 2.7 调仓频率

**月初调仓**（月度频率）

| 频率 | 优点 | 缺点 |
|------|------|------|
| 周度 | 信号更新快 | 换手率高、交易成本大 |
| **月度** | **换手可控、与策略月度选股对齐** | 信号滞后约15天 |
| 季度 | 交易成本极低 | 信号严重滞后，行业趋势可能反转 |

**月度调仓的具体操作**：
1. 每月最后一个交易日收盘后，重新计算26个行业的综合评分
2. 选出新的Top5行业
3. 与上期持仓行业对比：
   - 继续留在Top5的行业 → 保持该行业持仓
   - 新进入Top5的行业 → 下月第一个交易日建仓
   - 退出Top5的行业 → 下月第一个交易日清仓
4. 行业内个股选择交给第三层

### 3.3 选股策略：按市场状态匹配策略类型

**核心思路**：不同市场状态下，同一行业内应使用不同风格的选股策略。

| 市场状态 | 推荐选股策略类型 | 具体策略 | 选股因子方向 |
|---------|----------------|---------|------------|
| 🔴 强牛市 | 趋势型 | 索罗斯趋势投机、赛马动量 | 动量↑、量价共振↑、趋势跟随 |
| 🟠 震荡上行 | 混合型 | 攻防轮动、VWAP偏离趋势 | 动量+价值双因子、成交量确认 |
| 🟡 宽幅震荡 | 反转型 | 负反馈反转、短周期三维反转 | 短期超跌↑、均值回归↑、反转因子↑ |
| 🟢 窄幅震荡 | 防御型 | 好公司低吸 | 低估值↑、高ROE↑、低波动↑ |
| 🔵 震荡下行 | 防御型 | 好公司低吸、银行跷跷板 | 高股息↑、低Beta↑、防御属性 |
| ⚫ 恐慌熊市 | 防御型 | 好公司低吸 | 极低估值↑、现金流量↑、安全边际 |

### 3.4 行业内选股的具体执行方法

**Step 1 — 获取行业内股票列表**

```python
target_stocks = [s for s in stock_pool if industry_map[s] == target_industry]
```

**Step 2 — 按当前市场状态选择策略类型**

根据第一层输出的市场状态标签，确定选股策略：

```
if 状态 in ["强牛市"]:
    策略 = 动量选股
elif 状态 in ["震荡上行"]:
    策略 = 量价确认选股
elif 状态 in ["宽幅震荡"]:
    策略 = 反转选股
elif 状态 in ["窄幅震荡", "震荡下行", "恐慌熊市"]:
    策略 = 价值防御选股
```

**Step 3 — 行业内因子打分**

按选定策略计算因子值并排序：
