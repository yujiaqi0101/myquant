# 数据库结构说明

本文档描述 A股量化分析系统 SQLite 数据库的完整表结构。数据库文件路径：`data/aquant.db`，使用 WAL 模式。

---

## 一、行情数据

### 1. stock_daily - 股票日频数据

存储股票每日行情数据，是系统最核心的数据表。

**字段列表：**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| trade_date | DATE | NOT NULL | 交易日期 |
| stock_code | VARCHAR(20) | NOT NULL | 股票代码（如 000001.SZ） |
| open | REAL | | 开盘价 |
| high | REAL | | 最高价 |
| low | REAL | | 最低价 |
| close | REAL | | 收盘价 |
| volume | REAL | | 成交量 |
| amount | REAL | | 成交额 |
| vwap | REAL | | 成交量加权平均价 |
| pre_close | REAL | | 前收盘价 |
| suspend_flag | INTEGER | DEFAULT 0 | 停牌标记（1=停牌） |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**约束：** `UNIQUE(trade_date, stock_code)`

**索引：**

| 索引名 | 字段 | 说明 |
|--------|------|------|
| idx_stock_daily_code | stock_code | 按股票代码查询 |
| idx_stock_daily_date | trade_date | 按日期查询 |

### 5. trade_calendar - 交易日历

存储所有交易日日期，用于判断交易日/非交易日。

**字段列表：**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| trade_date | TEXT | PRIMARY KEY | 交易日期（如 2024-01-02） |

**约束：** `trade_date PRIMARY KEY`

**数据来源：** 东财掘金 `get_trading_dates_by_year` 接口，全量同步（1991年至今），每次同步先清空再全量替换，不受时间范围影响，是数据同步的第一步。

### 8. stock_pool_member - 股票池成员

存储股票池中的成员股票及其加入/移除时间。

**字段列表：**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| pool_id | INTEGER | NOT NULL | 股票池ID |
| stock_code | VARCHAR(20) | NOT NULL | 股票代码 |
| added_date | DATE | | 加入日期 |
| removed_date | DATE | | 移除日期（NULL表示仍在池中） |

**约束：**

- `FOREIGN KEY (pool_id) REFERENCES stock_pool(pool_id) ON DELETE CASCADE`

**索引：**

| 索引名 | 字段 | 说明 |
|--------|------|------|
| idx_pool_member_pool | pool_id | 按股票池查询成员 |
| idx_pool_member_stock | stock_code | 按股票查询所属池 |

**关系：** 多对一，关联 stock_pool.pool_id

## 六、系统

### 17. strategy_versions - 策略版本管理

存储策略的版本信息，支持同一策略多个版本共存，运行时只加载 `is_active=1` 的版本。

**字段列表：**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| strategy_id | VARCHAR(32) | NOT NULL | 策略目录ID（固定，同策略所有版本共享） |
| strategy_name | VARCHAR(100) | NOT NULL | 策略名称 |
| version | VARCHAR(20) | NOT NULL DEFAULT 'v1' | 版本号 |
| file_path | VARCHAR(500) | NOT NULL | 策略文件相对路径 |
| is_active | INTEGER | DEFAULT 1 | 是否激活（1=运行时加载） |
| description | TEXT | | 版本变更说明 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

**约束：** `UNIQUE(strategy_id, version)` — 同策略目录下版本号唯一

**索引：**

| 索引名 | 字段 | 说明 |
|--------|------|------|
| idx_strategy_versions_name | strategy_name | 按策略名查询 |
| idx_strategy_versions_active | is_active | 查询当前激活版本 |

**设计意图：** 策略逻辑调整时新建版本文件（如 `small_cap_v2.py`），数据库中注册新版本并自动激活，旧版本自动设为未激活。可通过 `db.set_active_version()` 回退到历史版本。

## 表间关系图

```
stock_pool (pool_id PK)
    |
    |-- 1:N --> stock_pool_member (pool_id FK)

execution_log (id PK)
    |
    |-- 1:N --> best_records (execution_id FK)

stock_daily (trade_date, stock_code UNIQUE)
index_daily (trade_date, index_code UNIQUE)
stock_info (stock_code UNIQUE)
qmt_instrument (stock_code UNIQUE)
index_constituent (index_code, stock_code UNIQUE)
trade_calendar (trade_date PK)
financial_data (stock_code, report_date, table_name UNIQUE)
valuation_result (stock_code, report_date, method UNIQUE)
valuation_summary (stock_code, report_date UNIQUE)
factor_registry (factor_id UNIQUE)
strategy_versions (strategy_id, version UNIQUE)
portfolio_analysis (analysis_date, portfolio_id UNIQUE)
factor_exposure (trade_date, portfolio_id, factor_name UNIQUE)
data_sync_log (id PK)
```
