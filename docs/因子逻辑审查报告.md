## 二、严重问题（必须修复）

### 问题1：CORR/COV 跨股票数据泄漏 🔴

**影响范围**：worldquant.py 约15个因子 + guotai.py 约20+个因子

**问题描述**：

代码中使用如下模式计算滚动相关系数：
```python
corr = series_a.groupby(level='stock_code').transform(
    lambda x: x.rolling(N).corr(series_b)
)
```

在 `groupby('stock_code').transform` 中，`lambda x` 中的 `x` 是单个股票的子序列，但 `series_b` 是完整的 MultiIndex Series。`x.rolling(N).corr(series_b)` 会在 rolling 窗口内按 index 对齐，由于 `series_b` 包含所有股票的数据，pandas 的 corr 可能引入其他股票的数据点。

**涉及因子（worldquant.py）**：alpha_002, alpha_003, alpha_006, alpha_013, alpha_014, alpha_015, alpha_016, alpha_017, alpha_022, alpha_026, alpha_036, alpha_040, alpha_044, alpha_045, alpha_068, alpha_074, alpha_075, alpha_078, alpha_081, alpha_085, alpha_086, alpha_092, alpha_095, alpha_096, alpha_098, alpha_099 等

**涉及因子（guotai.py）**：alpha_001, alpha_003, alpha_006, alpha_014, alpha_016, alpha_017, alpha_018, alpha_032, alpha_036, alpha_042, alpha_044, alpha_045, alpha_054, alpha_062, alpha_064, alpha_074, alpha_083, alpha_090, alpha_091, alpha_099 等

**正确做法**：应使用 `calculator.py` 中已有的 `ts_corr` 函数配合 `_apply_ts`：
```python
# 正确方式
corr = self._apply_ts2(series_a, series_b, ts_corr, window)
```
或确保在 lambda 内部只引用同一股票的子序列。

### 问题2：行业中性化因子中 groupby level 拼写错误 🔴

**影响范围**：worldquant.py 中所有行业中性化因子（alpha_048, 056, 058, 059, 063, 066, 067, 069, 070, 076, 079, 080, 082, 084, 087, 089, 090, 091, 093, 097, 100）

**问题描述**：

行业中性化因子中的 `corr` 计算使用了错误的 groupby level：
```python
corr = neutral_vwap.groupby(level='stock_date').transform(  # ❌ 错误！
    lambda x: x.rolling(5).corr(volume)
)
```

`stock_date` 不是有效的 index level 名称。正确的 level 应为 `trade_date`。这会导致所有行业中性化因子在运行时直接崩溃报错 `KeyError`。

**正确写法**：
```python
corr = neutral_vwap.groupby(level='trade_date').transform(  # ✅ 正确
    lambda x: x.rolling(5).corr(volume)
)
```

### 问题4：guotai.py alpha_055 的 TR 计算跨股票错位 🔴

**位置**：guotai.py alpha_055 方法

**问题描述**：
```python
tr = np.maximum(high - low, np.abs(high - close.shift(1)))  # ❌ 错误
```
在 MultiIndex `(trade_date, stock_code)` 上，`close.shift(1)` 会整体移位一行，导致不同股票的数据被错误混在一起。应改为：
```python
prev_close = self._apply_ts(close, ts_delay, 1)  # ✅ 正确
tr = np.maximum(high - low, np.abs(high - prev_close))
```
此外，TR 的完整公式缺少 `ABS(LOW - PREV_CLOSE)` 的比较。

## 三、中等问题（建议修复）

### 问题5：SMA 递归移动平均被错误替换为 ts_mean 🟡

**影响范围**：guotai.py alpha_024, alpha_028, alpha_030, alpha_057

**问题描述**：参考公式中使用 `SMA(x, d, m)` 递归公式 `(m*x + (d-m)*SMA_prev)/d`，代码全部使用 `ts_mean`（等权简单移动平均）。当 m=1 时，SMA 的权重是指数衰减 `[1/d, (d-1)/d * 1/d, ...]`，而 ts_mean 是等权 `[1/d, 1/d, ...]`，两者结果不同。

**建议**：实现一个 `sma(series, d, m)` 递归函数来替代。

---

### 问题6：DECAYLINEAR 被错误替换为 ts_mean 🟡

**影响范围**：guotai.py alpha_027

**问题描述**：GTJ_027 参考公式使用 `WMA`（线性衰减加权），代码使用 `ts_mean`（等权平均）。应使用已有的 `decay_linear` 函数。

---

### 问题7：worldquant.py alpha_029 简化实现与参考公式不一致 🟡

**问题描述**：参考公式为深层嵌套结构：
```
(min(product(rank(rank(scale(log(sum(ts_min(rank(rank((-1 * rank(delta((close - 1), 5))))), 2), 1))))), 1), 5) + ts_rank(delay((-1 * returns), 6), 5))
```
代码实现为简化版，缺少多层嵌套的 rank/scale/log/product 运算。

---

### 问题8：worldquant.py 多个因子公式简化 🟡

**影响因子**：alpha_021（布林带条件判断逻辑有偏差）、alpha_033（`(1 - (open/close)^1)` 应为 `(1 - (open/close))` 的 rank）

---

### 问题9：基本面因子全部使用模拟数据 🟡

**影响范围**：fundamental.py 全部22个因子

**问题描述**：所有因子的计算使用 `np.random.seed() + np.random.randn()` 生成的随机模拟数据，而非从财务数据库获取。这使得整个模块目前只能作为计算框架演示，无法用于实际生产。

---

### 问题10：fundamental.py calculate_profitability_factors() 遗漏因子 🟡

**问题描述**：`calculate_all()` 包含5个盈利因子，但 `calculate_profitability_factors()` 只包含4个，遗漏了 `PROF_EBITDA`。

---

### 问题11：fundamental.py _winsorize 去极值方法不正确 🟡

**问题描述**：对整个 Series 做分位数裁剪，但基本面因子数据具有 `(trade_date, stock_code)` 多级索引。正确做法应按 `trade_date` 分组后在每个截面上分别做去极值。

---

### 问题12：np.maximum/np.minimum 在 pandas Series 上的索引丢失风险 🟡

**影响范围**：guotai.py alpha_061, alpha_064, alpha_077, alpha_092, alpha_156

**问题描述**：`np.maximum(series1, series2)` 在某些 pandas/numpy 版本中可能返回 numpy array 而非 pandas Series，导致丢失 index。

## 七、结论

1. **工具函数层（calculator.py）**：实现正确，是整个因子系统的基础保障。
2. **WorldQuant 101因子**：已实现的约60个因子中，大部分非行业中性化因子的公式逻辑基本正确。**最严重的问题是行业中性化因子中 `groupby(level='stock_date')` 拼写错误，会导致21个因子全部崩溃**。
3. **国泰君安191因子**：191个因子全部有实现，但存在 **CORR跨股票数据泄漏**（影响20+因子）、**alpha_074变量未定义崩溃**、**alpha_055 TR计算错误**、**SMA/ts_mean混用** 等多个严重问题。
4. **基本面22因子**：公式逻辑全部正确，但全部使用随机模拟数据，无法用于实际分析。
