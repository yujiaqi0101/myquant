## 一、快速开始

### 1.1 获取因子值

```python
from src.factors import FactorService

# 初始化因子服务（自动读取配置的数据源）
service = FactorService()

# 获取某日某因子的值
pb_values = service.get_factor('pb', '2024-01-02')
print(pb_values['000001.SZ'])  # 平安银行的PB值

# 批量获取多个因子
factors = service.get_factors(['pb', 'roe'], '2024-01-02')
print(factors['pb']['000001.SZ'])
print(factors['roe']['000001.SZ'])
```

### 1.2 因子排名

```python
# 获取PB排名（升序，PB越低排名越高）
pb_ranks = service.rank('pb', '2024-01-02', ascending=True)
print(pb_ranks['000001.SZ'])  # 平安银行的PB排名

# 多因子综合排名（PB升序 + ROE降序）
combined = service.combined_rank(
    factor_names=['pb', 'roe'],
    date='2024-01-02',
    directions=[True, False]  # True=升序(越小越好), False=降序(越大越好)
)
```

### 1.3 选股

```python
# 获取PB最低的10只股票
top10 = service.top_n('pb', '2024-01-02', n=10, ascending=True)

# 获取PB最低的10%股票
top10pct = service.top_pct('pb', '2024-01-02', pct=10, ascending=True)
print(f"共选中 {len(top10pct)} 只股票")
```

## 二、可用因子列表

### 2.1 估值因子（Valuation）

| 因子名 | 中文名 | 说明 | 排名方向 | 支持数据源 |
|--------|--------|------|----------|-----------|
| `pb` | 市净率 | 股价/每股净资产，越低越好 | ↑ 升序 | eastmoney, database |
| `pe_ttm` | 市盈率TTM | 总市值/净利润（过去12个月） | ↑ 升序 | eastmoney |
| `ps_ttm` | 市销率TTM | 总市值/营业收入（过去12个月） | ↑ 升序 | eastmoney |
| `pcf_ttm` | 市现率TTM | 总市值/经营现金流（过去12个月） | ↑ 升序 | eastmoney |

### 2.2 盈利因子（Profitability）

| 因子名 | 中文名 | 说明 | 排名方向 | 支持数据源 |
|--------|--------|------|----------|-----------|
| `roe` | 净资产收益率 | 净利润/净资产，越高越好 | ↓ 降序 | eastmoney, database |
| `roe_weight` | 加权净资产收益率 | 加权平均ROE | ↓ 降序 | eastmoney |
| `roa` | 总资产收益率 | 净利润/总资产 | ↓ 降序 | eastmoney |
| `gross_margin` | 毛利率 | (营收-成本)/营收 | ↓ 降序 | eastmoney |
| `net_margin` | 净利率 | 净利润/营业收入 | ↓ 降序 | eastmoney |

### 2.3 成长因子（Growth）

| 因子名 | 中文名 | 说明 | 排名方向 | 支持数据源 |
|--------|--------|------|----------|-----------|
| `np_growth_q` | 净利润季度增长率 | 净利润季度同比 | ↓ 降序 | eastmoney |
| `revenue_growth_q` | 营收季度增长率 | 营业收入季度同比 | ↓ 降序 | eastmoney |

### 2.4 质量因子（Quality）

| 因子名 | 中文名 | 说明 | 排名方向 | 支持数据源 |
|--------|--------|------|----------|-----------|
| `debt_ratio` | 资产负债率 | 总负债/总资产 | ↑ 升序 | eastmoney |
| `current_ratio` | 流动比率 | 流动资产/流动负债 | ↓ 降序 | eastmoney |

## 三、API 详细说明

### 3.1 FactorService 类

#### `__init__(data_source=None, db_path=None)`

初始化因子服务。

**参数**:
- `data_source`: 数据源名称，`'eastmoney'` 或 `'database'`，None 则读取配置
- `db_path`: 数据库路径，None 则使用默认配置

**示例**:
```python
# 使用配置的数据源
service = FactorService()

# 强制使用东财掘金
service = FactorService(data_source='eastmoney')

# 强制使用本地数据库
service = FactorService(data_source='database')
```

---

#### `get_factor(factor_name, date, stock_pool=None)`

获取某日某因子的值。

**参数**:
- `factor_name`: 因子名称，如 `'pb'`, `'roe'`
- `date`: 查询日期，格式 `'YYYY-MM-DD'`
- `stock_pool`: 股票池代码列表，None 表示全市场

**返回**:
```python
{stock_code: factor_value}
# 例如: {'000001.SZ': 0.85, '000002.SZ': 1.23, ...}
```

---

#### `get_factors(factor_names, date, stock_pool=None)`

批量获取多个因子。

**参数**:
- `factor_names`: 因子名称列表，如 `['pb', 'roe']`
- `date`: 查询日期
- `stock_pool`: 股票池代码列表

**返回**:
```python
{factor_name: {stock_code: value}}
# 例如: {'pb': {'000001.SZ': 0.85}, 'roe': {'000001.SZ': 0.12}}
```

---

#### `rank(factor_name, date, ascending=None, stock_pool=None)`

获取某因子的全市场排名。

**参数**:
- `factor_name`: 因子名称
- `date`: 查询日期
- `ascending`: 排名方向，True=升序(越小排名越高)，None 使用因子默认方向
- `stock_pool`: 股票池代码列表

**返回**:
```python
{stock_code: rank}  # rank 从 1 开始
# 例如: {'000001.SZ': 15, '000002.SZ': 128, ...}
```

---

#### `combined_rank(factor_names, date, directions=None, stock_pool=None)`

多因子综合排名（各因子排名相加）。

**参数**:
- `factor_names`: 因子名称列表，如 `['pb', 'roe']`
- `date`: 查询日期
- `directions`: 各因子的排名方向列表，如 `[True, False]`，None 使用默认方向
- `stock_pool`: 股票池代码列表

**返回**:
```python
{stock_code: combined_rank}  # 值越小排名越高
```

**示例**:
```python
# PB升序(越小越好) + ROE降序(越大越好)
combined = service.combined_rank(
    factor_names=['pb', 'roe'],
    date='2024-01-02',
    directions=[True, False]
)
# 综合排名 = PB排名 + ROE排名
```

---

#### `top_n(factor_name, date, n=10, ascending=None, stock_pool=None)`

获取某因子排名前N的股票代码。

**参数**:
- `factor_name`: 因子名称
- `date`: 查询日期
- `n`: 取前N名
- `ascending`: 排名方向
- `stock_pool`: 股票池代码列表

**返回**:
```python
[stock_code1, stock_code2, ...]
```

---

#### `top_pct(factor_name, date, pct=10, ascending=None, stock_pool=None)`

获取某因子排名前N%的股票代码。

**参数**:
- `factor_name`: 因子名称
- `date`: 查询日期
- `pct`: 百分比，如 10 表示前10%
- `ascending`: 排名方向
- `stock_pool`: 股票池代码列表

**返回**:
```python
[stock_code1, stock_code2, ...]
```

### 3.2 因子注册表

#### `register_factor(name, field, source, category, description, default_ascending, data_sources)`

列出已注册因子。


```python

```

## 五、注意事项

### 5.1 数据源差异

| 数据源 | 优点 | 缺点 | 适用场景 |
|--------|------|------|----------|
| **eastmoney** | 数据完整，所有因子都支持 | 需要网络，有API限制 | 生产回测 |
| **database** | 本地计算，速度快 | 部分因子暂未实现 | 快速验证 |

### 5.2 缓存机制

FactorService 会自动缓存同日的因子数据，避免重复 API 调用：

```python
# 第一次调用会请求API
pb1 = service.get_factor('pb', '2024-01-02')

# 第二次调用直接返回缓存
pb2 = service.get_factor('pb', '2024-01-02')  # 无API请求
```

手动清除缓存：
```python
service.clear_cache('2024-01-02')  # 清除某日缓存
service.clear_cache()               # 清除全部缓存
```

### 5.3 错误处理

- 未知因子：返回空字典，记录错误日志
- API 失败：返回空字典，记录错误日志
- 数据缺失：该股票不会出现在返回结果中

## 七、常见问题

**Q: 为什么 database 数据源部分因子不支持？**  
A: 本地数据库存储的是原始财务报表（JSON格式），需要解析计算才能得到 PB/ROE 等指标。目前仅实现了基础框架，复杂计算待后续完善。

**Q: 如何查看所有可用因子？**  
A: 运行 `python -c "from src.factors.factor_registry import print_factor_list; print_factor_list()"`

**Q: 因子值是截面数据还是时间序列？**  
A: `get_factor()` 返回某一日期的截面数据。如需时间序列，需多次调用或直接使用 `FactorCalculator`。
