# 因子注册表功能计划

## Summary

在数据库中新增 `factor_registry` 表，记录系统所有因子的元信息（ID、名称、描述、分类、调用函数、关键词），并提供查询入口展示因子列表。

## Current State Analysis

### 现有因子数据
- `categories.py` 中 `ALL_FACTOR_META` 已有 65 个因子的元数据（name, category, description）
- 三个因子库：WorldQuantFactors(20)、GuotaiFactors(23)、FundamentalFactors(22)
- 每个因子的调用方式不同：
  - WQ/GTJ：`WorldQuantFactors(calculator).calculate_factor(factor_id: int)` 或 `alpha_xxx()` 方法
  - Fundamental：`FundamentalFactors(calculator).val_pe()` 等具体方法

### 数据库现状
- 共 12 张表，在 `DatabaseManager._init_database()` 中统一创建
- 添加新表只需追加 `CREATE TABLE IF NOT EXISTS` 语句

## Proposed Changes

### 1. 修改 `src/data/database.py` - 新增因子注册表

在 `_init_database()` 中添加 `factor_registry` 表：

```sql
CREATE TABLE IF NOT EXISTS factor_registry (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    factor_id TEXT NOT NULL,          -- 因子唯一标识，如 WQ_001, VAL_PE
    factor_name TEXT NOT NULL,        -- 因子名称，如 alpha_001, PE倒数
    category TEXT NOT NULL,           -- 分类枚举值，如 momentum, valuation
    category_name TEXT NOT NULL,      -- 分类中文名，如 动量类, 估值因子
    description TEXT,                 -- 因子描述（含输入输出参数说明）
    source TEXT NOT NULL,             -- 因子来源：worldquant / guotai / fundamental
    call_method TEXT NOT NULL,        -- 调用函数路径，如 WorldQuantFactors.calculate_factor(1)
    keywords TEXT,                    -- 关键词，逗号分隔，便于搜索
    status TEXT DEFAULT 'active',     -- 状态：active / deprecated / experimental
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(factor_id)
);
```

新增方法：
- `init_factor_registry()` - 从 `ALL_FACTOR_META` 初始化因子注册表数据
- `get_factor_registry(filters=None)` - 查询因子列表，支持按分类/来源/关键词筛选
- `search_factors(keyword)` - 按关键词搜索因子

### 2. 修改 `src/factors/categories.py` - 扩展因子元数据

为 `ALL_FACTOR_META` 中的每个因子补充 `source`、`call_method`、`keywords`、`input_params`、`output_params` 字段：

```python
"WQ_001": {
    "name": "alpha_001",
    "category": FactorCategory.MOMENTUM,
    "description": "时间序列动量信号强度。基于价格的时间序列变化计算动量信号，捕捉短期趋势。",
    "source": "worldquant",
    "call_method": "WorldQuantFactors.calculate_factor(1)",
    "keywords": "动量,时序,信号,趋势",
    "input_params": "FactorCalculator实例（内含价格数据、成交量数据）",
    "output_params": "pd.Series，索引为(trade_date, stock_code)，值为因子值（标准化后的排名）",
}
```

**输入参数说明格式：**
- 对于 WQ/GTJ 因子：`FactorCalculator实例（内含open/high/low/close/volume/amount价格数据）`
- 对于基本面因子：`FactorCalculator实例（内含价格数据），可选财务数据接口`

**输出参数说明格式：**
- 统一格式：`pd.Series，索引为(trade_date, stock_code)，MultiIndex结构`
- 值类型说明：`因子值为float，已做截面标准化处理` 或 `原始计算值未标准化`

### 3. 修改 `main.py` - 添加查询入口

新增 `--list-factors` 命令行参数，运行时以表格形式展示因子列表：

```
python main.py --list-factors                    # 列出所有因子
python main.py --list-factors --category momentum  # 按分类筛选
python main.py --list-factors --search 动量        # 按关键词搜索
```

输出格式：
```
=== 因子注册表 (共 65 个) ===

因子ID    | 名称       | 分类     | 来源        | 描述
WQ_001   | alpha_001  | 动量类   | WorldQuant | 时间序列动量信号强度
WQ_002   | alpha_002  | 成交量异常 | WorldQuant | 量价背离相关性
...
```
