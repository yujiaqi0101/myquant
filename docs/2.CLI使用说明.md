# CLI 使用说明

> 适用版本：统一事件驱动内核（`src/core/`）
> 引擎使用指南：[docs/引擎使用指南.md](引擎使用指南.md)

## 概述

A股量化分析系统采用多级命令结构，基于新版统一事件驱动内核架构。所有命令支持两种使用方式：

- **交互式**：不带子命令参数时，自动进入交互式菜单，通过编号选择操作
- **命令式**：直接指定子命令和参数，适合脚本和自动化场景

基本格式：

```bash
python main.py <一级命令> [子命令] [参数...]
```

## 一级命令列表

| 命令 | 说明 | 交互式入口 |
|------|------|-----------|
| `config` | 配置管理（Token、日志级别） | `python main.py config` |
| `data` | 数据管理（同步、校验、概览、清空） | `python main.py data` |
| `factor` | 因子管理（查询、注册、测试） | `python main.py factor` |
| `strategy` | 策略管理（列表、详情） | `python main.py strategy --list` |
| `backtest` | 运行回测（基于统一引擎 BacktestEngine） | `python main.py backtest -s <策略名>` |
| `result` | 回测结果管理（列表、查看、导出、删除） | `python main.py result --list` |
| `pool` | 股票池管理（创建、查看、添加、删除） | `python main.py pool --list` |
| `paper` | 模拟盘（多策略子账户，含 16 个子动作） | `python main.py paper` |
| `live` | 实盘（基于 LiveEngine，占位实现） | `python main.py live` |

## config 命令详解

配置管理命令，用于设置东财掘金 Token 和日志级别。

### 交互式

```bash
python main.py config
```

进入交互式菜单后，提供以下选项：

| 编号 | 操作 | 说明 |
|------|------|------|
| 1 | 查看当前配置 | 显示已配置的 Token、日志级别等信息 |
| 2 | 配置东财掘金 Token | 输入 Token 字符串 |
| 3 | 配置日志级别 | 选择 DEBUG / INFO / WARNING / ERROR |

### 命令式

```bash
# 查看当前配置
python main.py config --show

# 设置东财掘金 Token
python main.py config --token your_token_here

# 设置日志级别
python main.py config --log-level DEBUG

# 组合使用
python main.py config --show --log-level INFO
```

### 参数说明

| 参数 | 说明 | 可选值 |
|------|------|--------|
| `--token` | 设置东财掘金 Token | 字符串 |
| `--log-level` | 设置日志级别 | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `--show` | 显示当前配置 | 无需值 |

### 配置文件

所有配置统一存储在 `config/config.json` 中，包含凭证信息（东财掘金 Token）和日志设置。格式参考 `config/config.example.json`。

## data 命令详解

数据管理命令，提供数据同步、校验、查看数据概览和清空数据功能。数据同步通过 `SourceRegistry` 自动路由到对应数据源（东财掘金/通达信/线下文件），无需手动指定。

### 交互式

```bash
python main.py data
```

进入交互式菜单后，提供以下选项：

| 编号 | 操作 | 说明 |
|------|------|------|
| 1 | 自动增量同步（推荐） | 全量表全量刷新，增量表自动续传到今天 |
| 2 | 自定义同步（指定日期/步骤） | 可选择同步步骤和日期范围 |
| 3 | 校验数据完整性 | 检查数据质量 |
| 4 | 查看数据概览 | 显示数据库统计信息 |
| 5 | 清空数据 | 删除数据库文件 |

### 子命令

#### data auto-sync - 自动增量同步（推荐）

```bash
python main.py data auto-sync
```

一键自动同步，无需指定任何参数，适合日常数据更新。按固定 14 步顺序执行：

| 步骤 | 同步内容 | 模式 | 说明 |
|------|---------|------|------|
| 1 | 交易日历 | 全量 | 1991年至今全部交易日（每次清空重写） |
| 2 | 股票基本信息 | 全量 | 全部A股信息，自动回填申万行业分类 |
| 3 | 申万行业分类明细 | 全量 | 读取docs/目录下含"申万行业"的xlsx文件（先清空后写入） |
| 4 | ETF基本信息 | 全量 | 全部ETF信息 |
| 5 | 指数基本信息 | 全量 | 全部指数信息，自动标记11个核心指数（沪深300/中证500/上证50/创业板等） |
| 6 | 指数成分股 | 增量 | 核心指数成分股（按交易日遍历） |
| 7 | 通达信板块 | 脚本 | 调用通达信板块脚本同步概念/行业板块 |
| 8 | 股票日频行情 | 增量 | 5线程并发同步A股日K线 |
| 9 | 指数日频行情 | 增量 | 5线程并发同步指数日K线 |
| 10 | ETF日频行情 | 增量 | 5线程并发同步ETF日K线 |
| 11 | 财务主要指标 | 增量 | 按交易日遍历截面接口 |
| 12 | 财务衍生指标 | 增量 | 按交易日遍历截面接口（8批共142个字段） |
| 13 | 每日市值指标 | 增量 | 总市值/A股市值/企业价值等 |
| 14 | 估值数据 | 增量 | PE/PB/PS/PEG/股息率等 |

**增量断点续传机制：**
- 系统通过 `t_sync_data_log` 表记录每张增量表已成功同步的日期，作为续传的唯一可信凭证
- 每次执行时自动查询上次同步位置，从断点继续同步到最近交易日（周末/节假日自动回退到上一个交易日）
- 某张表从未成功同步过（或日志丢失）时，自动从 2021-01-01 开始补传
- 中途失败不会写入日志，下次重跑会从断点重新开始，INSERT OR REPLACE 保证重复同步安全
- 单张表同步成功后自动刷新该表的同步日志

无需任何参数，日常数据更新推荐使用此命令。

#### data sync - 自定义同步

```bash
# 同步数据（自动路由数据源）
python main.py data sync --start-date 20230101

# 指定日期范围
python main.py data sync --start-date 20230101 --end-date 20231231
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--start-date` | 起始日期 (YYYYMMDD) | 交互式输入 |
| `--end-date` | 结束日期 (YYYYMMDD) | 最新 |

#### data validate - 校验数据完整性

```bash
python main.py data validate
```

#### data status - 查看数据概览

```bash
python main.py data status
```

输出内容包括：数据库路径、各同步表记录数（交易日历、股票信息、日频数据、ETF、指数、板块、财务、财务衍生指标、估值、除权除息等）、股票池列表及成员数。

#### data clear - 清空数据

```bash
python main.py data clear
```

需要二次确认。将删除数据库文件，此操作不可恢复。

## backtest 命令详解

运行回测命令，基于新版统一事件驱动内核 `BacktestEngine`。数据从本地 SQLite 数据库读取。

### 基本用法

```bash
# 必须指定策略
python main.py backtest --strategy small_cap

# 指定时间范围
python main.py backtest -s small_cap --start-date 2024-01-01 --end-date 2024-06-30

# 传入策略参数
python main.py backtest -s small_cap --param top_n=5 --param rebalance_at=month_start
```

### 核心参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-s, --strategy` | 策略名称（必填，通过 `strategy --list` 查看可用策略） | - |
| `--start-date` | 回测开始日期 YYYY-MM-DD | 2024-01-01 |
| `--end-date` | 回测结束日期 YYYY-MM-DD | 2024-12-31 |
| `--initial-capital` | 初始资金 | 1,000,000 |
| `--benchmark` | 基准指数代码 | 000300.SH（沪深300） |

### 风控参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--no-risk-check` | 禁用 A 股风控（涨跌停/ST/T+1/新股/停牌 + 组合级检查） | False |
| `--max-position-pct` | 单持仓仓位上限 | 0.30 |
| `--max-positions` | 最多持仓股票数 | 10 |
| `--daily-stop-loss` | 日亏急停阈值（负数，-0.05 表示亏损 5% 急停） | -0.05 |

### 策略参数

| 参数 | 说明 |
|------|------|
| `--param KEY=VALUE` | 策略参数，可多次指定，如 `--param top_n=5 --param rebalance_at=month_start` |

`--param` 自动尝试将值转为 int/float/bool，失败则保留字符串。

### 输出参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--output-dir` | 报告输出目录 | reports |
| `--name` | 报告名称（默认自动生成 `backtest_<log_id>_<start>_<end>`） | - |

### 完整示例

```bash
# 基本回测（1个月数据，功能性验证）
python main.py backtest \
  -s small_cap \
  --start-date 2024-01-01 \
  --end-date 2024-01-31 \
  --param top_n=5 \
  --param rebalance_at=month_start

# 完整回测（5年数据，按项目规则7）
python main.py backtest \
  -s small_cap \
  --start-date 2019-01-01 \
  --end-date 2024-12-31 \
  --initial-capital 1000000 \
  --benchmark 000300.SH \
  --max-position-pct 0.30 \
  --max-positions 10 \
  --daily-stop-loss -0.05 \
  --param top_n=5 \
  --param rebalance_at=month_start

# 禁用风控（仅用于研究对比，不推荐）
python main.py backtest -s small_cap --no-risk-check
```

### 输出内容

回测完成后输出：

1. **控制台绩效摘要**：22+ 项绩效指标（总收益/年化/夏普/最大回撤/胜率/盈亏比等）
2. **报告目录** `reports/backtest_<log_id>_<start>_<end>/`：
   - `performance.json` - 绩效指标
   - `trades.json` - 交易记录
   - `snapshots.json` - 净值曲线
   - HTML 报告（自动生成）

## paper 命令详解

模拟盘命令，基于 `PaperEngine` 实现，**支持多策略子账户**：一个主账户可同时运行多个策略，资金独立隔离。

### 设计概念

- **主账户**：独立创建，不绑定具体策略，用于资金池管理
- **子账户**：与策略一一绑定，从主账户分配资金运行
- **资金二级分配**：先充值到主账户，再从主账户分配给各子账户
- **资金隔离**：每个子账户独立持仓/订单/成交/快照，互不干扰
- **停用而非删除**：子账户可停用（保留历史可查询），也可彻底删除（资金回收主账户）

### 典型流程

```bash
# 1. 创建主账户，初始资金 100 万
python main.py paper init --account acc_001 --capital 1000000

# 2. 充值 50 万到主账户（可选）
python main.py paper deposit --account acc_001 --amount 500000

# 3. 添加两个策略子账户，各分配 30 万
python main.py paper add-strategy --account acc_001 --strategy small_cap --capital 300000
python main.py paper add-strategy --account acc_001 --strategy pb_roe --capital 300000

# 4. 一键运行主账户下所有启用的子账户（跨策略运行）
python main.py paper run --account acc_001 --date 2024-06-28

# 也可单独运行某个子账户
# python main.py paper run --account acc_001 --strategy small_cap --date 2024-06-28

# 5. 查看主账户状态（含所有子账户汇总）
python main.py paper status --account acc_001

# 6. 查看子账户持仓
python main.py paper positions --account acc_001 --strategy small_cap
```

#### paper deposit - 主账户充值

```bash
python main.py paper deposit --account acc_001 --amount 500000
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--amount` | 充值金额（正数，必填） | - |

#### paper withdraw - 主账户提取

仅能提取未分配给子账户的可用现金。


| 参数 | 说明 | 默认值 |

### 子账户策略管理

#### paper add-strategy - 添加策略子账户

从主账户可用现金中分配资金给新子账户。

```bash
python main.py paper add-strategy --account acc_001 --strategy small_cap --capital 300000
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--strategy` | 策略名（必填） | - |
| `--capital` | 分配资金（必填） | - |

#### paper remove-strategy - 彻底删除子账户

删除子账户的全部数据（持仓/订单/成交/快照），剩余资金回收主账户。

```bash
python main.py paper remove-strategy --account acc_001 --strategy small_cap --yes
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--strategy` | 子账户策略名（必填） | - |
| `--yes` | 跳过确认提示 | False |

#### paper disable-strategy - 停用子账户

停用后子账户不再运行，但历史数据保留可查询，资金仍冻结。

```bash
python main.py paper disable-strategy --account acc_001 --strategy small_cap
```

#### paper enable-strategy - 启用子账户

```bash
python main.py paper enable-strategy --account acc_001 --strategy small_cap
```

#### paper list-strategies - 列出子账户

```bash
# 仅查看启用的子账户
python main.py paper list-strategies --account acc_001

# 含已停用的子账户
python main.py paper list-strategies --account acc_001 --all
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--all` | 包含已停用的子账户 | False |

### 运行与查询

#### paper run - 执行单日模拟交易

支持两种运行模式：
- **单策略模式**：指定 `--strategy`，只运行该子账户
- **多策略模式**：省略 `--strategy`，依次运行主账户下所有启用的子账户，并打印汇总

```bash
# 一键运行主账户下所有启用的子账户（推荐，跨策略运行）
python main.py paper run --account acc_001 --date 2024-06-28

# 只运行指定子账户
python main.py paper run --account acc_001 --strategy small_cap --date 2024-06-28

# 子账户不存在时自动创建（需指定 --strategy 和初始资金）
python main.py paper run --account acc_001 --strategy new_strategy --auto-create --initial-capital 200000

# 禁用风控（影响所有运行的子账户）
python main.py paper run --account acc_001 --no-risk-check
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--strategy` | 子账户策略名（省略时运行所有启用子账户） | 不指定 |
| `--date` | 交易日 YYYY-MM-DD | 今天 |
| `--initial-capital` | 子账户初始资金（仅 --auto-create 创建新子账户时使用） | 1,000,000 |
| `--no-risk-check` | 禁用 A 股风控 | False |
| `--auto-create` | 子账户不存在时自动创建（需指定 --strategy） | False |
| `--param` | 策略参数 KEY=VALUE，可多次指定 | 不指定 |

**多策略模式输出示例**：

```

--- 子账户: small_cap ---
运行模拟盘 [账户=acc_001, 策略=small_cap, 日期=2024-06-28]...
  单日运行完成
子账户摘要:
  现金: 250,000.00
  ...

--- 子账户: pb_roe ---
运行模拟盘 [账户=acc_001, 策略=pb_roe, 日期=2024-06-28]...
```

#### paper run-range - 批量执行区间内每日模拟交易

从 `t_trading_date` 读取区间内交易日，逐日执行模拟交易（适合补历史数据）。

```bash
# 批量运行指定策略（区间内每个交易日都跑一遍）
python main.py paper run-range --account acc_001 --strategy small_cap \
    --start-date 2024-01-01 --end-date 2024-06-28

# 批量运行主账户下所有启用的子账户
python main.py paper run-range --account acc_001 \
    --start-date 2024-01-01 --end-date 2024-06-28

# 禁用风控
python main.py paper run-range --account acc_001 --strategy small_cap \
    --start-date 2024-01-01 --end-date 2024-06-28 --no-risk-check
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--strategy` | 子账户策略名（省略时运行所有启用子账户） | 不指定 |
| `--start-date` | 起始日期 YYYY-MM-DD（必填） | - |
| `--end-date` | 结束日期 YYYY-MM-DD（必填） | - |
| `--no-risk-check` | 禁用 A 股风控 | False |
| `--param` | 策略参数 KEY=VALUE，可多次指定 | 不指定 |

#### paper adjust-cash - 调整子账户资金

追加分配（从主账户可用现金转入子账户）或回收资金（从子账户现金返还主账户）。

```bash
# 追加分配 10 万
python main.py paper adjust-cash --account acc_001 --strategy small_cap --amount 100000

# 回收 5 万到主账户
python main.py paper adjust-cash --account acc_001 --strategy small_cap --amount -50000
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 主账户ID（必填） | - |
| `--strategy` | 子账户策略名（必填） | - |
| `--amount` | 金额（正=追加分配，负=回收，必填） | - |

### 模拟盘特性

- **多策略子账户**：一个主账户可并行运行多个策略，资金独立隔离
- **资金二级分配**：主账户充值 → 子账户分配 → 子账户独立运行
- **每日模式**：`run` 由调度器定时调用，每次处理一个交易日；`run-range` 可批量执行区间内每日模拟交易
- **DB 持久化**：账户状态写入 `account_info` / `account_strategies` / `account_positions` / `account_orders` / `account_fills` / `account_snapshots` 6 张表
- **跨日恢复**：启动时 `load_state` 从 DB 读取上日子账户状态
- **末交易日追踪**：`account_strategies.last_trade_date` 记录子账户最近运行交易日，便于补记录
- **T+1 撮合**：当日订单次日开盘撮合（`next_open` 价格类型）
- **停用/启用**：子账户可停用保留历史，也可彻底删除回收资金

### 数据表结构

| 表名 | 说明 | 主键 |
|------|------|------|
| `account_info` | 主账户资金信息 | `account_id` |
| `account_strategies` | 子账户策略关联 | `(account_id, strategy_name)` |
| `account_positions` | 持仓快照 | `(account_id, strategy_name, symbol)` |
| `account_orders` | 订单记录 | `order_id` |
| `account_fills` | 成交记录 | `fill_id` |
| `account_snapshots` | 每日净值快照 | `(account_id, strategy_name, trade_date)` |

## 常见用法示例

### 1. 首次使用流程

```bash
# 1. 配置东财掘金 Token（数据同步必需）
python main.py config --token YOUR_TOKEN

# 2. 同步数据（推荐 auto-sync 一键同步）
python main.py data auto-sync

# 3. 查看可用策略
python main.py strategy --list

# 4. 运行回测（1个月数据，功能性验证）
python main.py backtest -s small_cap --start-date 2024-01-01 --end-date 2024-01-31

# 5. 查看回测结果
python main.py result --list
python main.py result --show reports/backtest_0001_2024-01-01_2024-01-31
```

### 2. 完整回测（5年数据）

```bash
python main.py backtest \
  -s small_cap \
  --start-date 2019-01-01 \
  --end-date 2024-12-31 \
  --initial-capital 1000000 \
  --benchmark 000300.SH \
  --param top_n=5 \
  --param rebalance_at=month_start
```

### 3. 模拟盘日常运行（多策略子账户）

```bash
# 1. 创建主账户
python main.py paper init --account acc_001 --capital 1000000

# 2. 添加策略子账户（分配资金）
python main.py paper add-strategy --account acc_001 --strategy small_cap --capital 500000

# 3. 每日运行（单日）
python main.py paper run --account acc_001 --strategy small_cap --date 2024-06-28

# 3b. 批量运行区间内每个交易日（补历史数据）
python main.py paper run-range --account acc_001 --strategy small_cap \
    --start-date 2024-01-01 --end-date 2024-06-28

# 4. 查看主账户状态（含子账户末交易日）
python main.py paper status --account acc_001

# 5. 查看子账户持仓
python main.py paper positions --account acc_001 --strategy small_cap

# 6. 查看成交记录（买卖明细）
python main.py paper trades --account acc_001 --strategy small_cap
```

### 3b. 自由买卖策略（手动交易）

`manual_trade` 策略用于手动买卖指定股票，通过 `--param` 参数指定交易指令：

```bash
# 1. 添加 manual_trade 子账户
python main.py paper add-strategy --account acc_001 --strategy manual_trade --capital 500000

# 2. 买入 100 股贵州茅台
python main.py paper run --account acc_001 --strategy manual_trade --date 2024-06-28 \
    --param symbol=600519.SH --param action=buy --param volume=100

# 3. 卖出 100 股贵州茅台
python main.py paper run --account acc_001 --strategy manual_trade --date 2024-06-30 \
    --param symbol=600519.SH --param action=sell --param volume=100

# 4. 查看成交记录
python main.py paper trades --account acc_001 --strategy manual_trade
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `symbol` | 目标股票代码（如 600519.SH） | 必填 |
| `action` | 操作方向：buy / sell | buy |
| `volume` | 交易数量（股，买入须为 100 的倍数） | 必填 |
| `price_type` | 价格类型：market / limit | market |

### 4. 数据增量同步

```bash
# 日常更新（推荐）
python main.py data auto-sync

# 查看数据概览
python main.py data status
```
