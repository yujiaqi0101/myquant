# CLI 使用说明

> 适用版本：统一事件驱动内核（`src/core/`）
> 引擎使用指南：[docs/引擎使用指南.md](引擎使用指南.md)

## 概述

A股量化分析系统采用多级命令结构，基于新版统一事件驱动内核架构。所有命令支持两种使用方式：

- **交互式**：不带子命令参数时，自动进入交互式菜单，通过编号选择操作
- **命令式**：直接指定子命令和参数，适合脚本和自动化场景

基本格式：

```bash
python main.py <一级命令> [子命令] [参数...]
```

## 一级命令列表

| 命令 | 说明 | 交互式入口 |
|------|------|-----------|
| `config` | 配置管理（Token、日志级别） | `python main.py config` |
| `data` | 数据管理（同步、校验、概览、清空） | `python main.py data` |
| `factor` | 因子管理（查询、注册、测试） | `python main.py factor` |
| `strategy` | 策略管理（列表、详情） | `python main.py strategy --list` |
| `backtest` | 运行回测（基于统一引擎 BacktestEngine） | `python main.py backtest -s <策略名>` |
| `result` | 回测结果管理（列表、查看、导出、删除） | `python main.py result --list` |
| `pool` | 股票池管理（创建、查看、添加、删除） | `python main.py pool --list` |
| `paper` | 模拟盘（基于 PaperEngine，含 5 个子动作） | `python main.py paper` |
| `live` | 实盘（基于 LiveEngine，占位实现） | `python main.py live` |

## config 命令详解

配置管理命令，用于设置东财掘金 Token 和日志级别。

### 交互式

```bash
python main.py config
```

进入交互式菜单后，提供以下选项：

| 编号 | 操作 | 说明 |
|------|------|------|
| 1 | 查看当前配置 | 显示已配置的 Token、日志级别等信息 |
| 2 | 配置东财掘金 Token | 输入 Token 字符串 |
| 3 | 配置日志级别 | 选择 DEBUG / INFO / WARNING / ERROR |

### 命令式

```bash
# 查看当前配置
python main.py config --show

# 设置东财掘金 Token
python main.py config --token your_token_here

# 设置日志级别
python main.py config --log-level DEBUG

# 组合使用
python main.py config --show --log-level INFO
```

### 参数说明

| 参数 | 说明 | 可选值 |
|------|------|--------|
| `--token` | 设置东财掘金 Token | 字符串 |
| `--log-level` | 设置日志级别 | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `--show` | 显示当前配置 | 无需值 |

### 配置文件

所有配置统一存储在 `config/config.json` 中，包含凭证信息（东财掘金 Token）和日志设置。格式参考 `config/config.example.json`。

## data 命令详解

数据管理命令，提供数据同步、校验、查看数据概览和清空数据功能。数据同步通过 `SourceRegistry` 自动路由到对应数据源（东财掘金/通达信/线下文件），无需手动指定。

### 交互式

```bash
python main.py data
```

进入交互式菜单后，提供以下选项：

| 编号 | 操作 | 说明 |
|------|------|------|
| 1 | 自动增量同步（推荐） | 全量表全量刷新，增量表自动续传到今天 |
| 2 | 自定义同步（指定日期/步骤） | 可选择同步步骤和日期范围 |
| 3 | 校验数据完整性 | 检查数据质量 |
| 4 | 查看数据概览 | 显示数据库统计信息 |
| 5 | 清空数据 | 删除数据库文件 |

### 子命令

#### data auto-sync - 自动增量同步（推荐）

```bash
python main.py data auto-sync
```

一键自动同步，无需指定任何参数，适合日常数据更新。按固定 14 步顺序执行：

| 步骤 | 同步内容 | 模式 | 说明 |
|------|---------|------|------|
| 1 | 交易日历 | 全量 | 1991年至今全部交易日（每次清空重写） |
| 2 | 股票基本信息 | 全量 | 全部A股信息，自动回填申万行业分类 |
| 3 | 申万行业分类明细 | 全量 | 读取docs/目录下含"申万行业"的xlsx文件（先清空后写入） |
| 4 | ETF基本信息 | 全量 | 全部ETF信息 |
| 5 | 指数基本信息 | 全量 | 全部指数信息，自动标记11个核心指数（沪深300/中证500/上证50/创业板等） |
| 6 | 指数成分股 | 增量 | 核心指数成分股（按交易日遍历） |
| 7 | 通达信板块 | 脚本 | 调用通达信板块脚本同步概念/行业板块 |
| 8 | 股票日频行情 | 增量 | 5线程并发同步A股日K线 |
| 9 | 指数日频行情 | 增量 | 5线程并发同步指数日K线 |
| 10 | ETF日频行情 | 增量 | 5线程并发同步ETF日K线 |
| 11 | 财务主要指标 | 增量 | 按交易日遍历截面接口 |
| 12 | 财务衍生指标 | 增量 | 按交易日遍历截面接口（8批共142个字段） |
| 13 | 每日市值指标 | 增量 | 总市值/A股市值/企业价值等 |
| 14 | 估值数据 | 增量 | PE/PB/PS/PEG/股息率等 |

**增量断点续传机制：**
- 系统通过 `t_sync_data_log` 表记录每张增量表已成功同步的日期，作为续传的唯一可信凭证
- 每次执行时自动查询上次同步位置，从断点继续同步到最近交易日（周末/节假日自动回退到上一个交易日）
- 某张表从未成功同步过（或日志丢失）时，自动从 2021-01-01 开始补传
- 中途失败不会写入日志，下次重跑会从断点重新开始，INSERT OR REPLACE 保证重复同步安全
- 单张表同步成功后自动刷新该表的同步日志

无需任何参数，日常数据更新推荐使用此命令。

#### data sync - 自定义同步

```bash
# 同步数据（自动路由数据源）
python main.py data sync --start-date 20230101

# 指定日期范围
python main.py data sync --start-date 20230101 --end-date 20231231
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--start-date` | 起始日期 (YYYYMMDD) | 交互式输入 |
| `--end-date` | 结束日期 (YYYYMMDD) | 最新 |

#### data validate - 校验数据完整性

```bash
python main.py data validate
```

#### data status - 查看数据概览

```bash
python main.py data status
```

输出内容包括：数据库路径、各同步表记录数（交易日历、股票信息、日频数据、ETF、指数、板块、财务、财务衍生指标、估值、除权除息等）、股票池列表及成员数。

#### data clear - 清空数据

```bash
python main.py data clear
```

需要二次确认。将删除数据库文件，此操作不可恢复。

| 5 | 测试因子计算 | 计算指定因子在指定日期的值 |
| 6 | 注册新因子 | 添加自定义因子 |

### 子命令

```bash

python main.py factor list

# 按分类筛选
python main.py factor list --category valuation

# 按数据源筛选
python main.py factor list --source eastmoney

# 按关键词搜索
python main.py factor list --keyword "市盈率"
```

| 参数 | 说明 |
|------|------|
| `--category` | 按分类筛选 |
| `--source` | 按数据源筛选 |
| `--keyword` | 按关键词搜索（匹配因子名和描述） |

#### factor info - 查看因子详情

```bash
python main.py factor info --name pe_ratio
```

| 参数 | 说明 | 是否必填 |
|------|------|---------|
| `--name` | 因子名称 | 是 |

输出内容：名称、分类、描述、API字段、数据来源、排名方向、支持的数据源。

#### factor test - 测试因子计算

```bash
# 使用默认日期
python main.py factor test --name pe_ratio

# 指定日期
python main.py factor test --name pe_ratio --date 2024-01-02
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--name` | 因子名称 | (必填) |

#### factor register - 注册新因子

```bash
python main.py factor register \
  --name custom_pe \
  --field pe_ratio \
  --category valuation \
  --description "自定义市盈率因子" \
  --ascending
```

| 参数 | 说明 | 是否必填 |
|------|------|---------|
| `--name` | 因子名称（英文） | 是 |
| `--field` | API字段名 | 是 |
| `--category` | 因子分类 | 是 |
| `--description` | 因子描述 | 否 |
| `--ascending` | 升序排名（越小越好） | 否（默认True） |

## backtest 命令详解

运行回测命令，基于新版统一事件驱动内核 `BacktestEngine`。数据从本地 SQLite 数据库读取。

### 基本用法

```bash
# 必须指定策略
python main.py backtest --strategy small_cap

# 指定时间范围
python main.py backtest -s small_cap --start-date 2024-01-01 --end-date 2024-06-30

# 传入策略参数
python main.py backtest -s small_cap --param top_n=5 --param rebalance_at=month_start
```

### 核心参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-s, --strategy` | 策略名称（必填，通过 `strategy --list` 查看可用策略） | - |
| `--start-date` | 回测开始日期 YYYY-MM-DD | 2024-01-01 |
| `--end-date` | 回测结束日期 YYYY-MM-DD | 2024-12-31 |
| `--initial-capital` | 初始资金 | 1,000,000 |
| `--benchmark` | 基准指数代码 | 000300.SH（沪深300） |

### 风控参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--no-risk-check` | 禁用 A 股风控（涨跌停/ST/T+1/新股/停牌 + 组合级检查） | False |
| `--max-position-pct` | 单持仓仓位上限 | 0.30 |
| `--max-positions` | 最多持仓股票数 | 10 |
| `--daily-stop-loss` | 日亏急停阈值（负数，-0.05 表示亏损 5% 急停） | -0.05 |

### 策略参数

| 参数 | 说明 |
|------|------|
| `--param KEY=VALUE` | 策略参数，可多次指定，如 `--param top_n=5 --param rebalance_at=month_start` |

`--param` 自动尝试将值转为 int/float/bool，失败则保留字符串。

### 输出参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--output-dir` | 报告输出目录 | reports |
| `--name` | 报告名称（默认自动生成 `backtest_<log_id>_<start>_<end>`） | - |

### 完整示例

```bash
# 基本回测（1个月数据，功能性验证）
python main.py backtest \
  -s small_cap \
  --start-date 2024-01-01 \
  --end-date 2024-01-31 \
  --param top_n=5 \
  --param rebalance_at=month_start

# 完整回测（5年数据，按项目规则7）
python main.py backtest \
  -s small_cap \
  --start-date 2019-01-01 \
  --end-date 2024-12-31 \
  --initial-capital 1000000 \
  --benchmark 000300.SH \
  --max-position-pct 0.30 \
  --max-positions 10 \
  --daily-stop-loss -0.05 \
  --param top_n=5 \
  --param rebalance_at=month_start

# 禁用风控（仅用于研究对比，不推荐）
python main.py backtest -s small_cap --no-risk-check
```

### 输出内容

回测完成后输出：

1. **控制台绩效摘要**：22+ 项绩效指标（总收益/年化/夏普/最大回撤/胜率/盈亏比等）
2. **报告目录** `reports/backtest_<log_id>_<start>_<end>/`：
   - `performance.json` - 绩效指标
   - `trades.json` - 交易记录
   - `snapshots.json` - 净值曲线
   - HTML 报告（自动生成）

## paper 命令详解

模拟盘命令，基于 `PaperEngine` 实现单日模拟交易。支持账户持久化、跨日恢复、T+1 撮合。

### paper run - 执行单日模拟交易

```bash
# 执行单日模拟交易
python main.py paper run --strategy small_cap --date 2024-06-28

# 指定账户和初始资金（仅首次创建账户时使用 initial-capital）
python main.py paper run --strategy small_cap --account acc_small_cap --initial-capital 1000000

# 禁用风控
python main.py paper run --strategy small_cap --no-risk-check
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--strategy` | 策略名（必填） | - |
| `--date` | 交易日 YYYY-MM-DD | 今天 |
| `--account` | 账户ID | `acc_<strategy>` |
| `--initial-capital` | 初始资金（仅首次创建账户时使用） | 1,000,000 |
| `--no-risk-check` | 禁用 A 股风控 | False |

### paper status - 查看所有账户状态

```bash
python main.py paper status
```

显示所有模拟盘账户的当前状态（现金/持仓/总资产/盈亏）。

### paper positions - 查看账户持仓

```bash
python main.py paper positions --account acc_small_cap
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 账户ID（必填） | - |

### paper reset - 清空账户历史

```bash
python main.py paper reset --account acc_small_cap --yes
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 账户ID（必填） | - |
| `--yes` | 跳过确认提示 | False |

### paper adjust-cash - 调整账户现金

```bash
# 充值 50 万
python main.py paper adjust-cash --account acc_small_cap --amount 500000

# 提取 20 万
python main.py paper adjust-cash --account acc_small_cap --amount -200000
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--account` | 账户ID（必填） | - |
| `--amount` | 金额（正=充值，负=提取，必填） | - |

### 模拟盘特性

- **每日模式**：`run` 由调度器定时调用，每次处理一个交易日
- **DB 持久化**：账户状态写入 `account_info` / `account_positions` / `account_orders` / `account_fills` / `account_snapshots` 表
- **跨日恢复**：启动时 `load_state` 从 DB 读取上日账户状态
- **T+1 撮合**：当日订单次日开盘撮合（`next_open` 价格类型）

## pool 命令详解

股票池管理命令，支持创建、查看、添加/移除成员、删除股票池。

```bash
# 列出所有股票池
python main.py pool --list

# 创建股票池
python main.py pool --create tech_pool --code TECH --desc "科技股精选"

python main.py pool --show tech_pool

python main.py pool --add tech_pool --import-csv stocks.csv

python main.py pool --remove tech_pool --stocks 000001.SZ

# 删除股票池
python main.py pool --delete tech_pool
```

| 参数 | 说明 |
|------|------|
| `-l, --list` | 列出所有股票池 |
| `--create <名称>` | 创建股票池 |
| `--code <代码>` | 股票池代码（与 --create 配合） |
| `--desc <描述>` | 股票池描述（与 --create 配合） |
| `--show <名称>` | 查看股票池详情和成员列表 |
| `--delete <名称>` | 删除股票池 |
| `--add <名称> --stocks <代码>` | 添加股票 |
| `--remove <名称> --stocks <代码>` | 移除股票 |
| `--import-csv <路径>` | 从CSV导入（与 --add 配合） |
| `--import-index <指数代码>` | 从指数成分股创建（与 --create 配合） |

### 1. 首次使用流程

```bash

python main.py config --token YOUR_TOKEN

# 2. 同步数据（推荐 auto-sync 一键同步）
```
