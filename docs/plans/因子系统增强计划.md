# 因子系统逻辑增强计划

## Summary

为因子系统增加两项逻辑增强：
1. **因子分类体系**：按技术指标类型分类（K线形态、成交量异常、VWAP偏离、动量类、波动率类等），支持按分类筛选因子
2. **基本面因子**：实现估值因子（PE/PB/PS/PCF）和盈利因子（ROE/ROA/净利润增速/营收增速等）

## Current State Analysis

### 现有因子系统结构

| 文件 | 功能 |
|------|------|
| `src/factors/calculator.py` | 基础因子计算器，提供时间序列和截面工具函数 |
| `src/factors/worldquant.py` | WorldQuant 101因子（20个已实现），无分类属性 |
| `src/factors/guotai.py` | 国泰君安Alpha191因子（23个已实现），仅有注释分类 |
| `src/factors/selector.py` | 因子筛选器，支持IC/IR筛选，无分类筛选 |

### 现有因子分类（非正式，仅注释）
- GuotaiFactors中有注释分类：量价相关、均值回复、动量、波动率、相关性、成交量、价格形态

### 数据库财务数据
探索确认：数据库中没有 `financial_statement` 表，无法直接读取财务数据。基本面料子需要从 QMT 接口实时获取或通过行情数据计算派生指标。

#### 2.2 因子返回数据格式

基本面因子的特殊性在于：需要使用前一个财务周期的数据（财报数据滞后发布），且数据不是每日更新而是每季度更新。

```python
class FundamentalFactors:
    """
    基本面因子计算器

    注意：基本面因子使用前推的财务数据，适用于横截面选股
    - 数据频率：季度（与财报发布同步）
    - 数据延迟：使用最近可获得的财报数据
    """

    def __init__(self, calculator):
        self.calculator = calculator

    def get_latest_financial_data(self, stock_codes, date):
        """获取指定日期最近可用的财务数据"""

    def calculate_valuation_factors(self, date):
        """计算估值因子"""

    def calculate_profitability_factors(self, date):
        """计算盈利因子"""

    def calculate_growth_factors(self, date):
        """计算成长因子"""

    def calculate_quality_factors(self, date):
        """计算质量因子"""

    def calculate_all(self, date):
        """计算所有基本面因子，返回因子字典"""
```

## Assumptions & Decisions

1. **基本面数据来源**：由于数据库中没有财务数据表，基本面因子采用以下策略：
   - 对于可以直接从行情数据计算的因子（如PE=收盘价/每股收益）使用市值数据和净利润估算
   - 对于需要完整财务数据的因子，提供计算接口，数据来源作为扩展点
   - 未来可对接 QMT 的财务数据接口

2. **因子分类标准**：采用技术指标分类法，与专业量化平台的分类标准对齐

3. **分类筛选的优先级**：因子可以属于多个分类（多标签），也可以只属于一个分类

---

## Verification Steps

1. **因子分类验证**：
   - 运行因子计算，确认因子能按分类正确分组
   - 使用 `selector.get_factors_by_category(FactorCategory.VWAP_DEVIATION)` 能返回所有VWAP偏离类因子

2. **基本面因子验证**：
   - 计算估值因子，确认返回值合理（PE倒数的数值范围）
   - 验证因子与其他因子的整合性（可以一起传入 Selector）

3. **单元测试**：
   - 验证因子分类元数据完整性（所有因子都有分类）
   - 验证分类筛选结果的正确性
