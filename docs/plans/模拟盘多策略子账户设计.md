# 模拟盘多策略子账户设计文档

> 日期：2026-07-04
> 状态：已确认，待实现

## 一、背景

当前模拟盘账号与策略是1对1绑定（`account_info.strategy_name` NOT NULL，PaperEngine 接收单个 strategy 实例）。用户需要一个账号同时运行多个策略，各策略资金独立隔离。

## 二、设计决策

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 隔离模式 | 子账户隔离 | 每个策略有独立资金/持仓，互不影响 |
| 资金分配 | 手动指定 | 用户为每个子账户指定资金额 |
| 实现方案 | 新增关联表 | account_strategies 表 + 现有表增加 strategy_name 列 |
| 主账户 | 独立创建 | 主账户不依赖策略，可单独创建 |
| 停用策略 | 停用而非删除 | disable 保留历史，remove 彻底删除 |
| 资金流转 | 二级分配 | 先给主账户充值，再从主账户向子账户分配 |

## 三、数据结构

### 3.1 新增 account_strategies 表

```sql
CREATE TABLE IF NOT EXISTS account_strategies (
    account_id        VARCHAR(64) NOT NULL,   -- 主账户ID
    strategy_name     VARCHAR(100) NOT NULL,  -- 策略名
    allocated_capital DOUBLE NOT NULL,        -- 初始分配资金
    cash              DOUBLE NOT NULL,        -- 子账户当前现金
    total_value       DOUBLE NOT NULL,        -- 子账户总资产（cash + 持仓市值）
    enabled           INTEGER NOT NULL DEFAULT 1,  -- 1=启用 0=停用
    created_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (account_id, strategy_name)
)
```

### 3.2 修改 account_info 表

- `strategy_name` 改为可空（主账户不绑定单一策略）
- 新增 `allocated_capital` 列（已分配给子账户的资金总额）

```sql
-- account_info 新结构
account_id        VARCHAR(64) PRIMARY KEY
strategy_name     VARCHAR(100)              -- 可空（主账户无策略绑定）
initial_capital   DOUBLE NOT NULL
cash              DOUBLE NOT NULL           -- 主账户可用现金（未分配）
allocated_capital DOUBLE NOT NULL DEFAULT 0 -- 已分配给子账户的资金
frozen            DOUBLE NOT NULL DEFAULT 0
total_value       DOUBLE NOT NULL           -- 主账户总资产 = cash + SUM(子账户.total_value)
peak_value        DOUBLE NOT NULL
updated_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP
```

### 3.3 修改现有4张表（增加 strategy_name 列）

| 表 | 主键/唯一键变更 | 新增列 |
|----|----------------|--------|
| account_positions | PK → (account_id, strategy_name, symbol) | strategy_name |
| account_orders | 无（order_id 仍为PK） | strategy_name |
| account_fills | 无（fill_id 仍为PK） | strategy_name |
| account_snapshots | UNIQUE → (account_id, strategy_name, trade_date) | strategy_name |

### 3.4 主从关系

```
account_info (主账户，1行/账户)
  ├─ account_strategies (子账户配置，N行/账户)
  ├─ account_positions (按 strategy_name 区分)
  ├─ account_orders    (按 strategy_name 区分)
  ├─ account_fills     (按 strategy_name 区分)
  └─ account_snapshots (按 strategy_name 区分)
```

## 四、资金流转模型

```
创建主账户:     account_info.cash = 1,000,000
添加子账户A:    account_info.cash -= 500,000 → 500,000
                account_info.allocated_capital += 500,000 → 500,000
                account_strategies[A].cash = 500,000
子账户A交易:    account_strategies[A].cash 变化（买入减少/卖出增加）
                account_strategies[A].total_value = cash + 持仓市值
停用子账户A:    清仓变现 → account_info.cash += 变现金额
                account_info.allocated_capital -= 初始分配
                account_strategies[A].enabled = 0（历史保留）
主账户总资产 = account_info.cash + SUM(account_strategies.total_value WHERE enabled=1)
```

## 五、CLI 设计

### 5.1 主账户管理

```bash
# 创建主账户（独立，不依赖策略）
python main.py paper init --account myaccount --capital 1000000

# 主账户充值
python main.py paper deposit --account myaccount --amount 500000

# 主账户提取
python main.py paper withdraw --account myaccount --amount 100000
```

### 5.2 子账户（策略）管理

```bash
# 添加子账户（从主账户分配资金）
python main.py paper add-strategy --account myaccount --strategy small_cap --capital 500000

# 停用子账户（清仓回收，历史保留）
python main.py paper disable-strategy --account myaccount --strategy small_cap

# 重新启用子账户（需重新分配资金）
python main.py paper enable-strategy --account myaccount --strategy small_cap --capital 500000

# 彻底删除子账户（清除所有数据）
python main.py paper remove-strategy --account myaccount --strategy small_cap --yes

# 查看子账户列表
python main.py paper list-strategies --account myaccount
```

### 5.3 运行

```bash
# 运行所有启用子账户
python main.py paper run --account myaccount

# 只运行指定子账户
python main.py paper run --account myaccount --strategy small_cap

# 指定日期
python main.py paper run --account myaccount --date 2024-07-04
```

### 5.4 查看

```bash
# 所有主账户
python main.py paper status

# 主账户详情+子账户
python main.py paper status --account myaccount

# 所有子账户持仓
python main.py paper positions --account myaccount

# 指定子账户持仓
python main.py paper positions --account myaccount --strategy small_cap
```

### 5.5 清空/调整

```bash
# 清空整个主账户
python main.py paper reset --account myaccount --yes

# 清空指定子账户
python main.py paper reset --account myaccount --strategy small_cap --yes

# 调整子账户现金
python main.py paper adjust-cash --account myaccount --strategy small_cap --amount 50000
```

## 六、PaperEngine 改动

### 6.1 增加 strategy_name 参数

```python
class PaperEngine:
    def __init__(
        self,
        strategy: Strategy,
        db: Any,
        account_id: str,
        strategy_name: Optional[str] = None,  # 新增：子账户策略名
        initial_capital: float = 1_000_000.0,
        ...
    ):
```

- `strategy_name` 用于持久化时标记子账户
- `save_state` / `load_state` 传入 `strategy_name` 作为子账户标识

### 6.2 run_one_day 流程不变

PaperEngine 的 `run_one_day(bar)` 内部逻辑不变，只是持久化时带上 `strategy_name`。

### 6.3 多策略运行由 CLI 层负责

CLI 的 `paper run --account X` 查询 `account_strategies` 表，对每个启用的子账户创建独立的 PaperEngine 实例并运行。
