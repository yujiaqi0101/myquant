 ## 背景
 
 原策略将 448 只股票池硬编码在 `_load_stock_pool` 函数中。当 `docs/股票与ETF清单.xlsx` 发生变化时，需要手动同步代码，容易出错。
 
 ## 改动步骤
 
 ### 1. 从 Excel 动态读取股票池
 
 - 新增 `_convert_code()` 函数，将 Excel 的 `sh600000`/`sz000001` 格式转换为掘金的 `SHSE.600000`/`SZSE.000001` 格式
 - 重写 `_load_stock_pool()`，使用 `openpyxl` 从 `docs/股票与ETF清单.xlsx` 读取股票代码
 - 支持多路径自动查找（相对路径 + 绝对路径回退）
 - 新增 `_load_fallback_pool()` 硬编码后备列表，Excel 读取失败时自动降级
 
 ### 2. 全局池外持仓清理
 
 - 新增 `STOCK_POOL_SET` 全局集合，用于 O(1) 判断股票是否在池内
 - `_do_trade()` 新增逻辑：强制卖出所有不在池内的历史持仓
 - `_soros_check()` 收窄：仅对池内持仓执行连续3日下跌减仓
 
 ### 3. 修复 run() 调用格式
 
 东财掘金客户端要求 `run(` 独占一行，第一个参数不能和 `run(` 在同一行：
 
 ```python
 # 错误格式
 run(strategy_id='...', filename='main.py',
 
 # 正确格式
 run(
     strategy_id='...',
     filename='main.py',
 ```
