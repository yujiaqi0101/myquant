# 风格轮动 ETF 策略 - 版本历史

## 策略 ID: 8b3c1d07

## 策略名称: style_rotation_etf

## 策略说明

在指定 ETF 池中，按 N 日累计收益率（动量）打分，月初调仓选 Top1 满仓持有。
适用于大盘风格轮动场景（如上证50ETF/沪深300ETF/中证500ETF 之间切换）。

## 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `momentum_period` | int | 20 | 动量计算周期（交易日） |
| `rebalance_at` | str | "month_start" | 调仓频率：month_start/month_end/week_start/daily |
| `top_n` | int | 1 | 选前 N 只 ETF 等权持有 |

## 使用指南

```bash
# 默认3只ETF轮动
python main.py backtest --strategy style_rotation_etf \
    --stocks 510050.SH,510300.SH,510500.SH \
    --start-date 2021-06-28 --end-date 2026-06-26 --engine vbt

# 查看策略详情
python main.py strategy --show style_rotation_etf
```

要点：
- `--stocks` 指定 ETF 代码列表（逗号分隔）
- 策略类 `asset_class = "etf"`，CLI 自动从 t_etf_daily 加载数据
- 不指定 `--stocks` 时加载全市场 ETF（数据量大，谨慎使用）

### 反向信号 sanity check

在不同动量周期下对比正向与反向信号收益：

| 周期(日) | 正向收益 | 反向收益 | 判定 |
|----------|---------|---------|------|
| 5  | 28.11%  | 87.26%  | FAIL |
| 10 | -13.86% | 123.67% | FAIL |
| **20** | **30.35%** | **28.13%** | **PASS** |
| 60 | -15.14% | 19.93%  | FAIL |
| 120 | 15.38% | 39.41% | FAIL |

结论：20日周期是唯一通过 sanity check 的（正向 > 反向），默认参数合理。
A股 ETF 市场短期反转效应极强（5/10日反向远超正向），20日是动量-反转平衡点。

## 扩展路径
- 本策略为单一资产（ETF）轮动策略
- 未来可扩展为两层选股策略：
  - 场景 A：最强指数 → 成分股 Top3（使用 `from_mixed_db` + `get_index_constituents`）
  - 场景 B：最大 ETF → 成分股 Top3（使用 `from_mixed_db` + `get_etf_constituents`，需先同步 t_stock_in_etf 数据）
